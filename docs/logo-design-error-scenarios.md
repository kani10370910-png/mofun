# Logo 设计功能异常场景规范

> 适用范围：品牌设计 → Logo 设计（ImageLogoPanel + LogoGallery + LogoDownloadModal）模块  
> 文档用途：前端异常处理实现参考

**接口说明**

| 功能 | 接口 | 格式 |
|------|------|------|
| 生成 Logo | Qwen-Image（本地部署） | 图片 URL / Base64 |
| 高清 PNG 导出 | Qwen-Image（本地部署） | PNG，可用于微信/网店 |
| 透明背景 PNG | 美图抠图接口 | PNG（透明通道） |
| 矢量 SVG 导出 | 怪兽科技矢量化接口 | SVG，可印刷/任意缩放 |

---

## 一、输入校验类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 品牌名称为空 | 点击「立即生成」时 `brand` 字段为空或全为空格 | 输入框标红，toast 提示："请输入品牌名称！"；不发起请求 |
| 品牌名称超长 | 品牌名称超过 20 个字符 | 输入时字符计数实时提示（如"16 / 20"）；超出后禁止继续输入，提示："品牌名称不超过 20 个字" |
| 品牌名称含敏感词 | 输入内容命中平台敏感词库 | 提交前本地校验，命中时 toast 提示："品牌名称包含不允许的词语，请修改后重试"；不发起请求 |
| 创意描述含敏感词 | 创意描述命中平台敏感词库 | 提交前本地校验，命中时 toast 提示："创意描述包含不允许的词语，请修改后重试"；不发起请求 |

## 二、Logo 生成类（Qwen-Image 本地）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 本地服务未启动 | Qwen-Image 本地服务宕机，fetch 抛出 ECONNREFUSED | 历史卡展示错误："Logo 生成服务暂时不可用，请联系管理员"；提供「重试」按钮 |
| 生成超时 | 请求超过 60s 无响应 | 历史卡展示错误："生成超时，请稍后重试"；提供「重试」按钮 |
| 生成结果为空 | 接口返回 200 但图片数组为空 | 历史卡展示提示："未能生成有效的 Logo，请尝试修改品牌名称或风格"；提供「重新生成」按钮 |
| 内容安全拦截 | 接口返回内容安全拒绝（如 HTTP 400 + 安全相关 message） | 历史卡展示提示："Logo 内容未通过安全审核，请调整品牌名称或创意描述"；不展示任何结果图 |
| 网络连接失败 | fetch 抛出网络异常（ECONNRESET / 断网） | 自动重试最多 2 次（间隔 1.5s）；重试均失败后历史卡展示："网络连接失败，请检查网络后重试"；提供「重试」按钮 |
| 接口返回错误码 | API 返回 4xx / 5xx | 将错误信息映射为中文展示（见下方映射表），不向用户暴露原始报错 |
| 生成耗时较长 | 生成任务超过 10s 仍进行中 | 加载文案分阶段切换（每 ~8s 一次）：① 正在理解品牌创意… → ② AI 正在设计 Logo 草稿… → ③ 优化细节与配色中… → ④ 即将完成，请稍等… |

### 错误码映射表

| 错误信息（含） | 展示文案 |
|---|---|
| `timeout` | 生成超时，请稍后重试 |
| `content` / `safety` / `policy` | 内容未通过审核，请修改品牌名称或描述 |
| `quota` / `limit` | 今日生成次数已达上限 |
| `model` / `unavailable` | 模型服务暂时不可用，请稍后重试 |
| `connect` / `econnreset` | 网络连接失败，请检查网络后重试 |
| 其他 / 兜底 | 生成失败，请稍后重试 |

## 三、导出下载类

### 3.1 高清 PNG（Qwen-Image 本地）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 本地服务未启动 | Qwen-Image 本地服务宕机 | 下载弹窗中「高清 PNG」选项展示错误状态："高清导出服务暂时不可用"；其他格式（透明 PNG / SVG）不受影响 |
| 导出超时 | 请求超过 30s 无响应 | toast 提示："高清 PNG 导出超时，请重试"；提供「重试」按钮，按钮恢复可点击 |
| 导出失败 | 接口返回非 200 | toast 提示："高清 PNG 导出失败，请重试"；提供「重试」按钮 |

### 3.2 透明背景 PNG（美图抠图接口）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 抠图服务不可用 | 美图接口宕机或返回 5xx | 下载弹窗中「透明背景 PNG」选项展示错误状态："抠图服务暂时不可用，请稍后重试"；其他格式不受影响 |
| 抠图超时 | 请求超过 30s 无响应 | toast 提示："透明背景导出超时，请重试" |
| 主体识别失败 | 抠图接口无法识别 Logo 主体（返回空结果或置信度过低） | toast 提示："自动抠图识别失败，可下载高清 PNG 后手动处理透明背景" |
| 抠图结果异常 | 返回图片尺寸为 0 或文件损坏 | 展示错误占位图，提示："透明背景处理异常，请重试或使用其他格式" |

### 3.3 矢量 SVG（怪兽科技矢量化接口）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 矢量化服务不可用 | 怪兽科技接口宕机或返回 5xx | 下载弹窗中「矢量 SVG」选项展示错误状态："矢量化服务暂时不可用"；其他格式不受影响 |
| 矢量化超时 | 请求超过 60s 无响应（矢量化通常较慢） | toast 提示："矢量化处理超时，请稍后重试" |
| 矢量化结果为空 | 接口返回空 SVG 或非法 SVG 内容 | toast 提示："矢量化失败，可下载高清 PNG 代替"；自动降级提示 |

### 3.4 通用导出异常

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| ZIP 打包失败 | JSZip 压缩或 `saveAs()` 抛出异常 | toast 提示："打包文件失败，请重新下载"（现有行为）；提供「重试」按钮 |
| 文件名含非法字符 | 品牌名称包含 `\ / : * ? " < > \|` 等保留字符 | 下载前自动将非法字符替换为 `_`；静默处理，不提示用户 |

## 四、预览展示类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| Logo 缩略图加载失败 | 历史卡片中 `<img>` 的 `onError` 触发（URL 失效） | 图片位置显示品牌名首字母大写作占位，背景使用该记录渐变色；提供「重新加载」按钮 |
| 放大预览加载失败 | zoom 模态中 `<img>` 加载失败 | zoom 模态内显示占位文字："预览加载失败"；提供「下载」按钮绕过预览 |
| 历史记录为空 | 当前会话无生成记录 + 演示历史已全部删除 | 展示空状态："还没有生成记录，填好左侧点「立即生成」试试"（现有行为） |
| 收藏状态刷新丢失 | 页面刷新后 `favs` 内存 Set 重置 | 属预期行为（收藏未持久化）；如需持久化，可将 `favs` 写入 localStorage |

## 五、存储与配额类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 本地存储空间不足 | 写入 `localStorage`（「我的作品」）时捕获 `QuotaExceededError` | toast 提示："本地存储空间不足，历史记录可能无法保存"；生成流程正常继续 |
| 每日生成次数耗尽 | API 返回配额耗尽（HTTP 429 / `quota_exceeded`） | 弹出配额提示弹层："今日免费生成次数已用完"；提供「明日再来」和「联系客服解锁次数」两个操作；生成按钮置灰 |

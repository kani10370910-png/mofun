# 「制作大片」详细优化方案（模块级）

> 适用模块：视频宣传 → 制作大片（`Studio` 组件，`/video?sub=studio` / `?sub=studio:step`）
> 文档性质：产品优化方案（PRD 前置，模块级细化）
> 视角：以「内容脚本（剧本 → 分镜）」为主线，逐个基础功能模块拆解现状与优化
> 版本：v2.0 ｜ 最后更新：2026-07-03

---

## 0. 阅读指引

本方案按 Studio 的 **10 个基础功能模块**逐一展开。每个模块统一结构：

- **功能定位**：这个模块在生产线里承担什么
- **现状实现**：当前代码怎么做的（已核对 `Studio.tsx`）
- **问题清单**：逐条列出缺陷
- **优化方案**：细化到交互、字段、状态、边界、异常
- **数据结构**：涉及的数据模型变更
- **验收要点**：可测试的完成标准

模块总览与优先级：

| 模块 | 名称 | 优先级 | 一句话优化方向 |
|------|------|--------|---------------|
| M1 | 项目与草稿管理 | P0 | 从「未命名项目」到可保存可续编的项目 |

| M10 | 顶栏与步骤导航 | P2 | 状态可视化 + 校验拦截 |

## M1 · 项目与草稿管理模块

### 功能定位
承载整个大片项目的生命周期：创建、命名、保存、续编、多项目管理。

### 现状实现
- 顶栏固定显示「未命名项目 · {步骤名} · {N}镜 / {T}s」（`Studio.tsx:305-307`）。
- 所有状态（script / settings / assets / shots）仅存内存 `useState`，**刷新即丢失**。
- 无项目命名、无保存、无草稿列表、无从历史续编。

### 问题清单
1. 项目名恒为「未命名项目」，不可改。
2. 无持久化——切走或刷新页面，所有编辑丢失。
3. 无「我的项目 / 草稿箱」入口，无法回到未完成的片子继续做。
4. 与「我的作品 / 仓库」体系割裂。

### 优化方案
- **项目命名**：顶栏项目名可点击改名（inline 编辑），默认「未命名项目_日期」。
- **草稿自动保存**：
  - 编辑防抖 2s 自动存一次（localStorage 或云端）。
  - 顶栏显示保存态：「已保存 / 保存中… / 保存失败（点击重试）」。
  - 存储写入捕获 `QuotaExceededError`，toast「本地空间不足，草稿可能未保存」但不阻断编辑。
- **草稿续编**：新增「我的项目」列表（缩略图 = 首镜封面、项目名、镜数/时长、更新时间、进度到第几步），点击回到对应步骤续编。
- **手动操作**：顶栏加「保存草稿」「另存为副本」「删除项目」（删除二次确认）。

### 数据结构
```
StudioProject {
  id
  name
  updatedAt
  step            // 上次编辑到第几步
  script
  settings
  assets[]
  shots[]
  coverPoster     // 首个 done 镜封面，用作草稿缩略图
}
```

### 验收要点
- 刷新页面后编辑内容不丢失。
- 可命名、可从草稿列表续编到正确步骤。
- 存储溢出有提示且不中断编辑。

## M2 · 剧本编辑模块

### 功能定位
内容脚本的**入口**：用户在此提供文案或要点，产出后续分镜的原料。

### 现状实现
- 单个 `textarea`，默认填茶叶文案（`DEFAULT_SCRIPT`），placeholder「输入产品/场景要点，或粘贴成稿文案…」（`Studio.tsx:405-410`）。
- 「AI 扩写剧本」：`aiScript()` 延迟 1.1s **向尾部追加一段写死的文字**（`Studio.tsx:146-159`），`aiBusy` 期间按钮转圈禁用。
- 「下一步 · 视频设定 →」跳步。

### 问题清单
1. 只有一个自由文本框，无结构引导，用户不知道该写什么、写多少。
2. AI 扩写是**固定字符串追加**，与用户内容无关，纯演示。
3. 无字数/时长预估提示（写多长文案 ≈ 多长视频没有反馈）。
4. 无行业模板，冷启动全靠用户自己写。
5. 与下游脱节：这里改了文案，需回到 M5 手动「重新拆分镜」才生效，容易脏数据。

### 优化方案
- **双模式入口**：
  - 「填要点」模式：结构化表单（产品/主体、核心卖点 3 条、目标受众、期望风格、CTA），适合不会写文案的用户。
  - 「粘贴成稿」模式：保留 textarea，适合已有文案。
- **AI 结构化生成**（替代固定追加）：
  - 基于要点/成稿调用后端，产出**结构化剧本**（分段：开场钩子 / 卖点段 / 场景段 / 行动号召），而非一坨文字。
  - 支持**整体重写**与**分段重写**（只重写"开场"）。
  - 超时（≥25s）或返回空：toast「剧本生成失败，请重试」，保留原文，按钮恢复可点。
- **实时预估**：文案下方显示「预计 ≈ N 镜 / ≈ Ts」，随字数与设定时长联动。
- **模板库入口**：顶部「从模板开始」（详见 M2 附：模板），选模板 → 填要点 → 套模板生成。
- **字数限制**：软上限提示（如 500 字），超出提示「文案偏长，建议精简或增加总时长」。
- **联动下游**：剧本变更后，若已有分镜，提示「剧本已修改，是否重新拆分镜？」（避免脏数据，但不强制）。

### 数据结构
```
Script {
  mode           // 'points' | 'raw'
  raw            // 成稿文案
  points {       // 要点模式
    subject, sellingPoints[], audience, styleHint, cta
  }
  sections[]     // AI 结构化结果：{ type: 'hook'|'point'|'scene'|'cta', text }
}
```

### 验收要点
- 两种模式均可产出可拆分的剧本。
- AI 生成结果结构化、可分段重写、失败有兜底。
- 时长/镜数预估随输入实时更新。

## M3 · 视频设定模块

### 功能定位
定义贯穿全片的全局参数：画幅、风格、时长、配音（及应补齐的配乐、字幕）。

### 现状实现
- 4 组 chip 单选（`SETTING_FIELDS`，`Studio.tsx:48-53`）：
  - 画幅：横屏 16:9 / 竖屏 9:16 / 方形 1:1
  - 整体风格：国风清新 / 真实纪实 / 活泼种草
  - 总时长：15s / 30s / 60s
  - 配音：温柔女声 / 沉稳男声 / 不配音
- 设定存 `settings` 对象；画幅用于 canvas 尺寸解析，配音用于时间轴展示。

### 问题清单
1. **配乐无选项**：时间轴音乐轨写死「背景音乐 · 舒缓」（`Studio.tsx:842`），用户无法选/换/关。
2. **字幕无开关**：字幕恒等于旁白且强制显示，不能关、不能改样式。
3. 风格仅 3 档，且未真正影响生成（仅文字）。
4. 总时长档位少（15/30/60），无自定义。
5. 无高清/清晰度选项（关系到额度与画质）。

### 优化方案
- **新增「配乐」设定**：曲库选择（舒缓/活力/国风/商务/无）+ 试听 + 音量；关联时间轴音乐轨真实生效。
- **新增「字幕」设定**：开关 + 样式（字体/位置/描边）；关闭时预览与导出均不烧录字幕。
- **画质设定**：清晰 720P / 高清 1080P，1080P 标注「消耗 2 倍额度」（与 M9 额度联动）。
- **风格扩充并生效**：风格作为提示词前缀真正注入分镜生成，而非仅展示。
- **总时长**：档位 + 「自定义」输入（校验 5–180s）。
- **设定变更联动**：改总时长/画幅后提示对分镜时长/画幅的影响（如重算每镜时长）。

### 数据结构
```
Settings {
  ratio          // 画幅
  style          // 风格
  duration       // 总时长（支持自定义秒数）
  voice          // 配音
  bgm { track, volume }   // 新增：配乐
  caption { on, font, position, stroke }  // 新增：字幕
  quality        // 新增：720p | 1080p
}
```

### 验收要点
- 配乐可选可试听，导出音轨与选择一致。
- 字幕开关真实影响预览与导出。
- 1080P 正确计入 2 倍额度。

## M4 · 场景角色道具模块

### 功能定位
定义出镜元素，**目标是让 AI 在各分镜中保持人物/产品/场景一致性**。

### 现状实现
- 默认 3 张卡片（`Studio.tsx:107-111`）：高山云雾茶园(场景) / 采茶姑娘(角色) / 白茶罐装(道具)。
- 卡片显示 emoji + 名称 + 类型 tag，右上「×」删除。
- 「＋ 添加元素」：新增卡片，**名称恒为「新元素」、类型恒为「道具」、emoji 从固定池轮取**（`Studio.tsx:465-480`）。

### 问题清单
1. 添加的元素**名称、类型都不可编辑**，永远是「新元素/道具」，无实际意义。
2. 元素只有 emoji，**无参考图**，AI 无从"看到"该角色/产品长什么样。
3. 元素**未与任何镜头绑定**，也未注入生成——所谓"保持一致性"完全没有落点。
4. 无分组/排序，多了会乱。

### 优化方案
- **卡片可编辑**：点击卡片进入编辑（名称输入、类型选择：场景/角色/道具、描述文本）。
- **参考图上传**：每个元素可上传参考图（校验 JPG/PNG/WEBP、≤10MB，格式/体积不合规拦截 + toast），作为一致性锚点。
- **绑定镜头**（关键）：在 M5 每个镜头可勾选出镜元素；生成该镜时，将绑定元素的**参考图 + 描述注入提示词**，实现跨镜一致。
- **元素库复用**：可从「仓库/我的素材」选已有图作为元素（复用 `LibraryPickerModal`）。
- **分组展示**：按 场景 / 角色 / 道具 分组，支持排序。
- **空态与上限**：允许 0 元素（纯文本生成）；上限提示（如 ≤12 个）。

### 数据结构
```
Asset {
  id
  name           // 可编辑
  kind           // 场景 | 角色 | 道具
  desc           // 一致性描述
  refImg         // 参考图（一致性锚点）
  emoji          // 无图时的占位
}
Shot.assetRefs = [assetId...]   // 镜头 → 元素绑定
```

### 验收要点
- 元素可改名/改类型/传参考图。
- 镜头绑定的元素参考图确实进入该镜生成。
- 同一角色跨镜视觉一致性明显改善。

## M5 · 分镜脚本模块（核心）

### 功能定位
内容脚本的**心脏**：把剧本转成一组可逐镜执行的分镜，是本方案优化的重中之重。

### 现状实现
- `makeShots(script, total)`（`Studio.tsx:56-79`）：按 `。；！？\n` 切句 → 兜底按逗号切 → `slice(0,6)` 硬上限 6 镜 → 每镜时长 = `clamp(3,6, round(total/句数))`。
- 每镜 `Shot = { line, camera, dur, poster, status, pct }`；`camera = CAMERAS[i % 6]` 按索引轮转。
- 分镜列表每项（`Studio.tsx:499-525`）：缩略图 + 「镜头 i · {运镜}」 + `line` 输入框 + 时长「−/＋」(2–10s) + 删除。
- 操作：「＋添加镜头」（默认 4s、line="新镜头：补充画面描述"）、「按剧本重新拆分镜」、「下一步」。

### 问题清单
1. **`line` 一个字段兼作画面描述与口播旁白**，无法分别控制。
2. **运镜按索引轮转、界面不可改**，与画面内容无关。
3. 无**景别**概念（远/全/中/近/特）。
4. **硬上限 6 镜**，长片做不了；时长机械均分，不贴合内容节奏。
5. **镜头不可拖拽排序**。
6. 元素（M4）**无法绑定到镜头**。
7. 「重新拆分镜」直接**覆盖全部**，用户手改会丢失（无合并/无确认）。
8. 缩略图是海报样张占位，与画面描述无关。

### 优化方案
- **四要素结构化**（对齐 M2/M4）：每镜拆为
  - 画面描述 `shotDesc`（生成提示词）
  - 口播旁白 `narration`（TTS 配音）
  - 字幕 `caption`（默认继承旁白，可独立编辑）
  - 调度：运镜 `camera` + 景别 `shotSize` + 出镜元素 `assetRefs`
- **运镜/景别可控**：每镜运镜下拉（6 种）+ 景别下拉（远/全/中/近/特），并给"与画面匹配"的智能建议。
- **镜头排序**：支持拖拽调整顺序（当前完全不可调）。
- **智能拆分引擎**（替代机械切句）：按叙事节奏拆分、镜数按总时长动态定（去 6 镜上限）、每镜自动产出四要素与建议运镜/景别/元素；AI 不可用降级为标点切分。
- **非破坏式重拆**：「重新拆分镜」改为可选「保留我的手动修改 / 全部重来」，或提供 diff 预览再确认，避免覆盖用户编辑。
- **单镜操作补齐**：复制镜头、锁定镜头（重拆时不动）、时长上限放宽（2–15s）。
- **缩略图对齐内容**：M6 生成后回填真实首帧作为缩略图。

### 数据结构
```
Shot {
  id
  shotDesc       // 画面描述（生成提示词）
  narration      // 口播旁白
  caption        // 字幕（默认 = narration）
  camera         // 运镜（可选）
  shotSize       // 景别：远|全|中|近|特
  assetRefs[]    // 出镜元素
  dur            // 时长 2–15s
  locked         // 重拆时是否保留
  poster / status / pct / variants[]
}
```

### 验收要点
- 画面/口播/字幕三字段独立可编。
- 运镜、景别用户可改并影响生成。
- 镜头可拖拽排序、可复制、可锁定。
- 重拆不无声覆盖用户手改。

## M6 · 分镜视频生成模块

### 功能定位
把每个分镜真正变成视频片段，是成片的素材来源。

### 现状实现
- `genShot(id)`（`Studio.tsx:191-204`）：状态机 `idle → gen → done`，进度 6% 起每 240ms +11%，封顶 92%，1.7–2.4s 后置 100%。**纯进度动画，非真实生成**，画面仍是海报样张。
- 卡片三态（`Studio.tsx:549-584`）：idle 显「生成」按钮 / gen 显进度条 / done 显播放图标+时长+「已生成」，底部「重生成」。
- 「批量生成全部」`genAll()` 错峰 360ms 依次触发。

### 问题清单
1. 是**模拟进度**，没有接真实图/视频模型。
2. 无失败态——真实生成必然有超时/审核/额度失败，当前完全没处理。
3. 每镜只有一个结果，**无多版本/换一张**。
4. 无额度感知——批量生成 = 批量扣额度，用户无预估无确认。
5. done 后画面仍是占位海报，未回填真实帧。

### 优化方案
- **接入真实生成**：单镜调用图/视频模型，注入该镜四要素 + 绑定元素参考图 + 全局风格。
- **健全状态机**：`idle → queued(排队中) → gen(进度) → done / failed`。
  - 失败态卡片显示原因（映射后中文）+「重试」；`fail_reason` 映射：超时/内容审核/模型不可用/兜底（复用一句话成片的映射规范）。
  - 进度分段推进（排队→生成→收尾放缓），避免卡 100%。
- **多版本**：done 后「换一张/再生成」产出候选，缩略图切换选用（`variants[]`）。
- **额度联动**：
  - 批量生成前弹确认「本次将生成 N 镜，约消耗 N 次额度（1080P×2），是否继续」。
  - 额度耗尽（429/quota）弹配额弹层「今日次数已用完」+「明日再来 / 联系客服」，生成按钮置灰。
  - 失败镜头标注「已退还额度」。
- **回填真实帧**：done 后抽取首帧作为该镜缩略图（跨域失败回退占位，不破图）。

### 数据结构
```
Shot.variants = [{ id, videoUrl, poster, chosen }]
Shot.status = 'idle'|'queued'|'gen'|'done'|'failed'
Shot.failReason
```

### 验收要点
- 单镜/批量真实生成，失败有原因与重试。
- 支持多版本切换。
- 额度预估、确认、耗尽弹层、失败退还齐全。

## M7 · 视频预览播放器模块

### 功能定位
把已生成分镜合成连续预览，让用户在导出前确认成片效果。

### 现状实现
- 空态（无 done 镜）：提示 +「去生成分镜视频」（`Studio.tsx:601-612`）。
- `FilmPlayer`（`Studio.tsx:631-762`）：canvas + rAF 按顺序连播各镜 Ken Burns，播放/暂停、进度拖动、镜头 x/y 标记、分镜 tick。
- 「导出长视频」按钮。

### 问题清单
1. 预览**只有画面**，无配音、无配乐、无字幕——与最终成片不一致。
2. 画面是海报 Ken Burns，非真实生成的视频片段。
3. 无单镜跳转（点分镜直接跳到该镜）。
4. 无逐镜微调入口（预览发现问题要退回 M5/M6）。

### 优化方案
- **音画同步预览**：预览合成真实配音（TTS 旁白）+ 配乐 + 字幕烧录，所见即所得。
- **真实片段拼接**：done 镜用真实 `videoUrl` 顺序播放，替代 Ken Burns 占位（保留占位为降级）。
- **分镜跳转**：进度条分镜 tick 可点击跳转；侧边镜头缩略条点击定位。
- **就地微调**：预览下方每镜「编辑此镜」快捷入口，跳回对应镜的 M5/M6。
- **加载失败降级**：某镜 `videoUrl` 失效时该段回退封面+字幕，不黑屏，提示可重生成。

### 验收要点
- 预览包含配音/配乐/字幕，与导出一致。
- 可点击分镜跳转、可就地进入微调。
- 单镜加载失败不影响整体播放。

## M8 · 时间轴模块

### 功能定位
多轨可视化：直观展示视频/配音/字幕/音乐的时间分布。

### 现状实现
- `Timeline`（`Studio.tsx:790-846`）：4 轨——视频（分镜段+封面）、配音（`settings.配音` 全条）、字幕（各镜 line 分段）、音乐（写死「舒缓」全条）。
- 有 playhead 装饰，但**纯展示，不可编辑、不可拖动**。

### 问题清单
1. 时间轴**只读**，不能拖拽调整镜头时长/顺序。
2. 音乐轨写死「舒缓」，配音/字幕轨也不可在轴上操作。
3. playhead 与预览播放**不联动**（不随播放移动）。
4. 无缩放，长片时轨道拥挤。

### 优化方案
- **播放联动**：playhead 跟随 M7 预览实时移动；点轴 seek。
- **视频轨可编辑**：拖拽镜头段边缘改时长、拖拽整段调顺序（与 M5 双向同步）。
- **音乐/配音轨操作**：音乐轨点击换曲/调音量；配音轨按镜显示旁白、可静音某镜。
- **字幕轨编辑**：点字幕段就地改文案（与 M5 caption 同步）。
- **缩放**：时间轴支持横向缩放，长片可放大精修。

### 验收要点
- 轴上拖拽改时长/顺序，与分镜数据同步。
- playhead 与预览联动。
- 音乐/字幕可在轴上调整。

## M9 · 导出与交付模块

### 功能定位
成片的最终出口——决定用户的劳动成果能否沉淀与流转。

### 现状实现
- `exportFilm()`（`Studio.tsx:218-291`）：校验 `recordSupported()` 与至少 1 镜 → canvas 逐镜 Ken Burns → `MediaRecorder` 录制 → 下载 `制作大片_N镜.{ext}`。
- 顶栏「导出视频」显示「导出中 X%」。
- **仅本地下载，无其他去向**。

### 问题清单
1. 唯一出口是本地下载，**无「存入我的作品/仓库」、无「提交审核」**，与其他模块闭环割裂。
2. 导出画面是 Ken Burns 占位，非真实片段合成。
3. 导出**不含音轨**（无配音/配乐/字幕烧录）。
4. 无浏览器不支持时的降级路径。
5. 无导出参数选择（清晰度/格式/是否烧录字幕）。
6. 无额度结算提示。

### 优化方案
- **多去向交付**：导出成功后提供
  - 下载到本地（保留）
  - 存入「我的作品 / 仓库」（写入作品库，缩略图=首镜）
  - 提交审核（进审核流，对齐平台其他模块）
- **真实合成**：用真实片段 + 配音 + 配乐 + 字幕合成，而非 Ken Burns 占位。
- **导出参数**：清晰度（720/1080）、格式（MP4 优先）、是否烧录字幕、是否含音轨。
- **健壮性**：
  - 不支持 `MediaRecorder` 时降级（提示 + 服务端合成或下载封面）。
  - 并发导出拦截（导出中再点提示「正在导出，请稍候」）。
  - 跨域下载走同源代理，保证 MP4 落盘。
  - 存储写入溢出提示但不中断。
- **额度结算**：导出/生成完成提示消耗与剩余额度；1080P 计 2 倍。

### 验收要点
- 成片可下载、可入库、可提交审核。
- 导出含音画字幕，与预览一致。
- 不支持环境有降级，失败可重试。

## M10 · 顶栏与步骤导航模块

### 功能定位
全局操作与流程编排：返回、项目信息、一键生成、导出、6 步导航。

### 现状实现
- 顶栏（`Studio.tsx:298-317`）：返回（仅历史入口）、项目信息文本、「一键生成全部」、「导出视频」。
- 左侧步骤条（`Studio.tsx:320-338`）：6 步，状态 done/on/idle，**任意步可点击跳转**。
- 沉浸模式（`from=history`）隐顶栏、显返回。

### 问题清单
1. 步骤可自由跳转但**无前置校验**——可跳到「分镜视频」却还没拆分镜。
2. 步骤状态仅按索引位置判 done，非按内容真正完成判定（如第 4 步没拆镜也可能显示已完成）。
3. 「一键生成全部」在无分镜时点击无意义反馈。
4. 无全局进度感（做到百分之多少）。
5. 无退出保存提醒（离开丢草稿）。

### 优化方案
- **前置校验与引导**：跳步时若前置未完成，允许跳但给顶部提示条「请先在『分镜脚本』拆出镜头」并高亮待办步。
- **真实完成判定**：步骤 done 依据内容（有剧本/有设定/有分镜/有生成结果），而非索引。
- **全局进度**：顶栏显示整体完成度（如「4/6 步 · 3/8 镜已生成」）。
- **一键生成前置**：无分镜时点击引导去 M5；有分镜时走 M6 额度确认。
- **离开保护**：有未保存改动时离开/返回二次确认（配合 M1 自动保存后可弱化为提示）。
- **快捷操作**：顶栏加「保存草稿」「预览」快捷键与按钮。

### 验收要点
- 跳步有合理校验与引导，不出现空步骤死胡同。
- 步骤完成态反映真实内容进度。
- 顶栏有全局进度与离开保护。

## 成功指标

- **脚本一次成型率**：AI 分镜无需大改可用的比例（目标 ≥ 60%）。
- **平均编辑时长**：剧本到开始生成的耗时（目标 −40%）。
- **分镜→成片转化率**：进入 M5 后最终导出成片的比例。
- **成片交付率**：导出后入库/提交审核的比例。
- **模板使用率**：走模板 vs 空白起草的占比。
- **生成成功率 / 一致性满意度**：M6 真实生成的成功率与跨镜一致性主观评分。

## 风险与依赖

- **模型依赖**：智能拆分、真实生成、一致性注入依赖后端算法能力与时延预算，需与算法侧对齐接口。
- **成本**：动态镜数 + 真实生成增加额度消耗，需与计费策略联动（M6/M9 已含额度设计）。
- **数据迁移**：Shot 单字段 → 四要素、Asset 增字段，需对旧草稿做无损迁移（M1）。
- **范围控制**：P0 先保「结构化 + 闭环」，模板/一致性/多轨编辑按验证结果排期。

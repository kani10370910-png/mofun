# 活动设计功能异常场景规范

> 适用范围：品牌设计 → 活动（ImageEventPanel）模块  
> 文档用途：前端异常处理实现参考

---

## 一、输入校验类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 画面描述为空（文生图） | 点击「立即生成」时 `eventForm.input.trim() === ""`，且当前为「文生图」Tab | toast 提示："请输入画面描述！"；不发起 API 请求 |
| 关键词敏感词拦截 | 画面描述或修改需求命中平台敏感词库（色情 / 暴力 / 毒品等） | 提交前本地校验，命中时 toast 提示："包含不允许的词语，请修改后重试"；不发起 API 请求 |
| 修改需求为空（图生图） | 点击「立即生成」时修改需求为空且未选图片处理预设，且当前为「图生图」Tab | toast 提示："请输入修改需求或选择一个图片处理预设！"；不发起 API 请求 |
| 参考图未上传（图生图） | 点击「立即生成」时未上传参考图且未从仓库选图，且当前为「图生图」Tab | toast 提示："请先上传或从仓库选参考图片！"；不发起 API 请求 |
| 参考图格式不合规 | 上传文件扩展名不在白名单（仅允许 JPG / PNG / WEBP） | 文件选择后立即拦截，toast 提示："仅支持 JPG、PNG、WEBP 格式图片"；不进入上传流程 |
| 参考图体积超限 | 上传文件体积超过 10 MB | 文件选择后立即拦截，toast 提示："图片大小不能超过 10 MB，请压缩后重试"；不进入上传流程 |
| 自定义尺寸无效 | 图片尺寸选「自定义」时，宽或高输入为空 / 0 / 小于 64px | 点击生成时 toast 提示："请填写有效的自定义宽高（最小 64px）！"；不发起 API 请求 |

## 二、生成过程类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 生成超时 | 90s 内 API 无响应（串行多张 × 重试耗时累积） | 进度卡停止，展示错误文案："生成超时，请稍后重试"；生成按钮恢复可点击 |
| 网络连接失败 | fetch 抛出网络异常（断网 / ECONNRESET） | 自动重试最多 3 次（退避 1s / 2s / 3s）；全部失败后进度卡显示："网络连接失败，请稍后重试" |
| 内容安全审核拦截 | API 返回 HTTP 400 且错误信息含 `content` / `safety` / `policy` 关键词 | 进度卡展示："描述内容未通过安全审核，请调整后重试"；不展示任何生成图片；不重试 |
| 每日配额耗尽 | API 返回 HTTP 429 或错误信息含 `quota` / `limit` 关键词 | 进度卡展示："今日生成次数已达上限"；弹出配额提示弹层，提供「明日再来」和「联系客服解锁次数」两个操作 |
| 生成结果为空 | API 返回 200 但所有图片 URL 均为空 | 进度卡展示："未能生成合适的结果，请尝试修改描述或参考图" |
| 生成失败（fail_reason 映射） | API 返回 `fail_reason` 字段或错误信息 | 将错误码映射为中文展示（见下方映射表），不向用户暴露原始错误信息 |
| 部分图片生成失败 | 多张生成时部分 URL 为空，仍有成功图片 | 成功图片正常展示；toast 提示："已生成 X/Y 张（部分超时），已存入「我的作品」" |
| 长时生成进度反馈 | 生成任务进行中（pct < 100） | 加载文案分阶段切换（每 ~8s 一次）：① 正在构思画面… → ② AI 正在排版构图… → ③ 细化视觉细节中，稍等片刻… → ④ 即将完成，请耐心等待… |

### fail_reason 映射表

| fail_reason（含）| 展示文案 |
|---|---|
| `timeout` | 生成超时，请稍后重试 |
| `content` / `safety` / `policy` | 内容未通过审核，请修改描述 |
| `quota` / `limit` | 今日生成次数已达上限 |
| `model` / `unavailable` | 模型暂时不可用，请稍后重试 |
| `network` / `connect` | 网络连接失败，请稍后重试 |
| 其他 / 兜底 | 生成失败，请稍后重试 |

## 三、图片展示类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 生成图片加载失败 | `<img>` 的 `onError` 触发（URL 失效、CDN 超时） | 图片位置显示灰色占位（破图图标）；底部展示「重新加载」按钮，点击后重置 src 重试 |
| 图片二次审核不通过 | 图片 URL 可访问但内容被 CDN 降级（404 / 纯色图） | 与加载失败共用 imgError 展示；其余合规图片正常展示 |
| 行头参考图预览失效 | 图生图行 meta 区的 refImg 缩略图加载失败 | `onError` 时隐藏该缩略图，不影响其他行内容展示 |
| 行内错误状态展示 | `row.error` 非空且进度 `pct === 100` | 进度卡区域居中展示错误文案（使用 `.lh-fail` 样式），配图标说明失败原因 |

## 四、存储与配额类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 本地存储空间不足 | 写入 `localStorage` 时捕获 `QuotaExceededError` | toast 提示："本地存储空间不足，历史记录可能无法保存"；生成流程正常继续，不因存储失败中断 |
| 每日生成次数耗尽 | API 返回配额耗尽（HTTP 429 / `quota_exceeded`） | 弹出配额提示弹层："今日免费生成次数已用完"；提供「明日再来」（关闭）和「联系客服解锁次数」两个操作；生成按钮置灰 |
| 存入「我的作品」失败 | `addWork()` 内部异常（存储写入失败） | toast 提示："作品保存失败，图片仍可正常使用"；不中断图片展示流程 |

## 五、工具辅助功能类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 联想扩写失败 | 调用 `/api/generate`（scene=`t2i-associate`）网络错误或超时 | toast 提示："联想扩写失败，请稍后重试"；输入框内容保持用户原始输入不变 |
| 联想扩写结果为空 | API 返回 200 但流式内容为空 | toast 提示："联想扩写未返回内容，请重试"；输入框内容不变 |
| 图转文识别失败 | 调用 `/api/vision` 网络错误或 API 拒绝 | 图转文面板展示内联错误文案："图片识别失败，请重试"；提供「重新识别」按钮；关闭面板后主表单不受影响 |
| 画面风格预览图加载失败 | 风格选择浮层中某张预览图 `onError` 触发 | 该风格卡改为纯色占位块（保留风格名称文字）；其余风格正常展示；不影响风格选择功能 |

# 一句话成片功能异常场景规范

> 适用范围：视频宣传 → 一句话成片（OnelineVideo）模块，含「文生视频 T2V」/「图生视频 I2V」双 Tab
> 文档用途：前端异常处理实现参考

---

## 一、输入校验类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 提示词为空（文生视频） | T2V 下未输入提示词也未选择场景即点「立即生成」 | toast 提示："请输入提示词或选择场景！"；不进入安全预检与生成流程 |
| 首帧未上传（图生视频） | I2V 下未上传首帧图即点「立即生成」 | toast 提示："请先上传首帧图！"；不进入生成流程 |
| 首尾帧缺尾帧 | I2V 开启「首尾帧」开关但仅上传首帧 | toast 提示："首尾帧模式需上传尾帧图！"；不进入生成流程 |
| 运动描述为空（图生视频） | I2V 已上传首帧但运动描述为空 | toast 提示："请输入运动描述！"；不进入生成流程 |
| 参考图格式不合规 | 上传首/尾帧文件扩展名不在白名单（仅允许 JPG / PNG / WEBP） | 文件选择器已用 `accept` 限制；拖拽上传时需 JS 二次校验，命中非白名单立即拦截，toast 提示："仅支持 JPG、PNG、WEBP 格式图片"，不生成预览 |
| 参考图体积超限 | 上传首/尾帧文件体积超过 10 MB | 文件选择后立即拦截，toast 提示："图片大小不能超过 10 MB，请压缩后重试"；不进入上传/预览流程 |
| 提示词超长 | 提示词输入超过 500 字 | 输入框 `maxLength` 硬限制在 500 字，无法继续输入 |
| 敏感词安全预检拦截 | 提示词 / 运动描述命中敏感词库（反动 / 暴恐 / 色情 / 血腥 等） | 点「立即生成」后进入「内容安全检测中…」，命中时按钮下方红字提示"⚠ 内容安全预检未通过，请修改提示词"，toast："内容安全预检未通过：含敏感词，请修改后重试"；不发起生成，约 2.6s 后自动清除拦截态 |

## 二、生成过程类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 视频生成超时 | 真实视频模型请求超过前端 450s 窗口，或网关返回 HTTP 504 | 该记录卡置为失败态，展示："生成超时（视频耗时过长）" |
| 网络 / 模型生成失败 | `/api/video` 抛出网络异常或返回非成功状态、无 videoUrl | 记录卡置为失败态，展示后端返回的失败原因（无则兜底"生成失败，请重试"）；toast 同步提示 |
| AI 扩写失败 | 「AI 扩写」调用 `/api/video-prompt` 超时（≥ 25s）或返回空 | toast 提示："优化失败，请重试"；保留用户原提示词不变，扩写按钮恢复可点 |
| 智能匹配风格推断失败 | 风格选「智能匹配」但 `/api/video-style-infer` 超时（≥ 6s）或返回空 | 静默降级：不追加风格描述，按原提示词继续生成，不打断主流程、不弹错误 |
| 字段组装服务不可用 | 文生视频 `/api/video-generate` 超时（≥ 8s）或失败 | 静默降级为前端手动组装（风格追加 / 智能匹配），生成流程正常继续，用户无感知 |
| 关键帧生成失败 | 需要生成关键帧时 `/api/image` 全部失败 | 降级为无关键帧的封面回退方案，生成流程不中断（演示态回退 Ken Burns / 海报池） |
| 长时生成进度反馈 | 生成任务进行中 | 状态分阶段推进：① 排队中（"排队中，预计等待 1 分钟"）→ ② 生成中进度条（4%→85% 平滑推进，"N% · 视频生成中"）→ ③ 完成跳 100%；后段刻意放缓，避免进度条卡满 100% 却仍在等待 |
| 生成结果为空 | 请求成功但未返回可用 videoUrl | 记录卡置为失败态，走「网络 / 模型生成失败」同一兜底文案；不展示空白播放器 |
| 生成失败（fail_reason 映射） | 后端返回结构化错误码 | 将英文错误码映射为中文展示（见下方映射表），不向用户暴露原始堆栈 / HTTP 细节 |

### fail_reason 映射表

| fail_reason（含）| 展示文案 |
|---|---|
| `timeout` / HTTP 504 | 生成超时（视频耗时过长），请稍后重试 |
| `content` / `safety` | 内容未通过审核，请修改描述 |
| `model` / `unavailable` | 模型暂时不可用，请稍后重试 |
| 其他 / 兜底 | 生成失败，请重试 |

## 三、画面展示类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 封面提取失败 | 从视频抽取首帧时跨域 CORS 阻断或 12s 超时 | 静默回退：优先用原生 `<video preload="metadata">` 直接显示首帧，不出现破图 |
| 视频加载失败（播放器） | 播放器内 videoUrl 失效 / CDN 超时 | 播放器降级为静态封面 + 提示词字幕展示；不显示空白黑屏；补充"视频加载失败，可尝试重新生成"提示 |
| 首帧预览加载失败 | I2V 上传预览图 `onError` | 上传框回退到默认占位（灰底 + 图标），可重新点击上传 |

## 四、下载导出类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 并发下载拦截 | 上一段下载 / 录制未结束又点「下载视频」 | toast 提示："视频正在生成中，请稍候…"；不启动第二次录制，避免资源竞争 |
| 浏览器不支持录制 | 环境无 `MediaRecorder` 或 canvas `captureStream` | 演示记录降级为下载封面 JPG，toast："当前浏览器不支持视频录制，已下载封面图" |
| 真实视频跨域下载 | 下载真实视频文件时 CDN 跨域导致 `download` 失效 | 通过同源代理 `/api/proxy-video` 下载，保证文件名与 MP4 落盘，toast："已开始下载视频（MP4 · 含音画同步音轨）" |

## 五、存储与配额类（后期确认费用后可能更改）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 本地存储空间不足 | 生成成功后写入 `localStorage`（存入「我的作品」）捕获 `QuotaExceededError` | toast 提示："本地存储空间不足，历史记录可能无法保存"；视频生成与播放正常继续，不因存储失败中断 |
| 生成失败退还额度 | 任一生成任务最终失败 | 记录卡状态说明明确标注"生成遇到问题，额度已退还"，避免用户误以为已扣费 |
| 高清额度提示 | 视频质量选择 1080P | 参数区展示提示："高清消耗 2 倍额度"，让用户在提交前知悉消耗 |
| 每日生成次数耗尽 | 后端返回配额耗尽（HTTP 429 / `quota_exceeded`） | 弹出配额提示弹层："今日免费生成次数已用完"；提供「明日再来」与「联系客服解锁次数」；生成按钮置灰 |

## 六、音频与播放类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 关闭声音仍有音轨 | 记录 `withAudio=false` 但真实视频文件自带音轨 | 播放器用 `ref` 强制 `muted`，保证「关闭声音」的记录播放时确实无声 |
| 无声记录导出 | `withAudio=false` 的记录下载 | 不合成任何音轨，导出纯视频文件；避免把提示词读稿混入历史演示视频 |

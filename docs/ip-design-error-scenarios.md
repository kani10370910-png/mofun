# IP 设计功能异常场景规范

> 适用范围：品牌设计 → IP 设计（ImageIpPanel）模块  
> 文档用途：前端异常处理实现参考

---

## 一、输入校验类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 关键词敏感词拦截 | 用户输入的 IP 名称或描述命中平台敏感词库 | 提交前本地校验，命中时输入框下方显示红色提示："包含不允许的词语，请修改后重试"；不发起 API 请求 |
| 品牌 / 商标名保护 | 输入已知品牌名或商标名 | 弹出提示弹层："检测到品牌或商标名称，为规避版权风险，建议使用自定义名称"；提供「继续生成」和「修改描述」两个操作 |
| 参考图格式不合规 | 上传文件扩展名不在白名单（仅允许 JPG / PNG / WEBP） | 文件选择后立即拦截，toast 提示："仅支持 JPG、PNG、WEBP 格式图片"；不进入上传流程 |
| 参考图体积超限 | 上传文件体积超过 10 MB | 文件选择后立即拦截，toast 提示："图片大小不能超过 10 MB，请压缩后重试"；不进入上传流程 |

## 二、生成过程类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 生成超时 | API 请求在客户端超时（≥ 60s 无响应） | 结果区展示超时提示卡："生成超时，可能是服务繁忙，请稍后重试"；提供「重试」按钮 |
| 网络连接失败 | fetch 抛出网络异常（ECONNRESET / 断网） | 自动重试最多 2 次（间隔 1.5s）；重试均失败后展示错误卡："网络连接失败，请检查网络后重试"；提供「重试」按钮 |
| 内容安全审核拦截（服务端） | API 返回内容安全拒绝（如 `content_policy_violation` / HTTP 400 + 安全相关 message） | 结果区展示提示卡："描述内容未通过安全审核，请调整后重试"；不展示任何生成图片；不提供重试按钮 |
| 生成结果为空 | API 返回 200 但图片列表为空数组 | 结果区展示空状态提示："未能生成合适的结果，请尝试修改描述或参考图"；提供「重新生成」按钮 |
| 生成失败（fail_reason 映射） | API 返回 `fail_reason` 字段 | 将英文错误码映射为中文展示（见下方映射表），不向用户暴露原始错误信息 |
| 长时生成进度反馈 | 生成任务耗时超过 10s 仍进行中 | 加载文案分阶段切换（每 ~8s 一次）：① 正在理解您的 IP 创意… → ② AI 正在绘制形象草稿… → ③ 细化线条与色彩中，稍等片刻… → ④ 即将完成，请耐心等待… |

### fail_reason 映射表

| fail_reason（含）| 展示文案 |
|---|---|
| `timeout` | 生成超时，请稍后重试 |
| `content` / `safety` | 内容未通过审核，请修改描述 |
| `quota` / `limit` | 今日生成次数已达上限 |
| `model` / `unavailable` | 模型暂时不可用，请稍后重试 |
| 其他 / 兜底 | 生成失败，请稍后重试 |

## 三、图片展示类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 生成图片加载失败 | `<img>` 的 `onError` 触发（URL 失效、CDN 超时） | 图片位置显示灰色占位图（破图图标）；底部显示「重新加载」按钮，点击后重置 src 重试；若重载仍失败展示文案："图片加载失败，可尝试重新生成" |
| 图片二次审核不通过 | 图片 URL 可访问但平台二次内容审核判定不合规 | 该图片位置显示遮罩："此图片未通过内容审核"；不提供下载 / 收藏 / 使用操作；其余合规图片正常展示 |

---

## 四、存储与配额类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 本地存储空间不足 | 写入 `localStorage` 时捕获 `QuotaExceededError` | toast 提示："本地存储空间不足，历史记录可能无法保存"；生成流程正常继续，不因存储失败中断 |
| 每日生成次数耗尽 | API 返回配额耗尽（HTTP 429 / `quota_exceeded`） | 弹出配额提示弹层："今日免费生成次数已用完"；提供「明日再来」（关闭）和「联系客服解锁次数」两个操作；生成按钮置灰 |

---

## 五、方案建议类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|-------------|
| 提案方向展示为空 | 调用 IP 创意提案 API 后返回空列表 | 提案区展示空状态提示："暂无方案建议，请补充更多 IP 描述后重试"；提供「重新生成提案」按钮 |
| 提案方向生成失败 | 提案 API 网络错误或超时 | 提案区展示错误状态："方案加载失败"；提供「重试」按钮；不影响主生成流程 |

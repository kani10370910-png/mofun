# 网络店招设计 · 竞品分析与功能方案

> 背景：魔方智绘「品牌设计 → 店招设计」入口已保留（`/image?sub=signage`），当前为「功能建设中」；尺寸占位含「线上店招 1920×150」「实体门头 300×80cm」。  
> 本文聚焦**网络店招**（电商店铺招牌 / Banner），实体门头作二期延伸。  
> 调研对象：创客贴、稿定设计、图怪兽、美图设计室（及同类模板/AI 电商工具共性）；海外 neon/sign 定制器仅作能力对照，非本期主竞品。

---

## 1. 竞品功能全集（按能力域）

### A. 平台与尺寸合规

| 功能 | 说明 | 代表产品 |
|---|---|---|
| 平台尺寸预设 | 淘宝/天猫 PC 店招、全屏通栏、无线端店招；京东/拼多多/美团店招等一键选尺寸 | 创客贴、稿定、图怪兽 |
| 安全区引导 | 提示中间有效区（如 PC 中间约 750～990px）、无线端中心安全区，避免文字被裁切 | 专业装修教程 + 稿定/创客贴模板内隐含 |
| 体积/格式约束 | JPG/PNG/GIF；常见 ≤200～300KB；支持动图 GIF（帧数限制） | 平台规范驱动，工具侧导出时压缩 |
| 店招 + 导航一体 | 1920×150 页头背景 + 中间可点模块（950/990）组合思路 | 天猫/淘宝装修实践，模板工具常「整条店招」交付 |

**常见线上尺寸（需内置为预设）**

| 场景 | 推荐像素 | 备注 |
|---|---|---|
| 淘宝/天猫 PC 默认招牌 | 950 × ≤120 | 过高影响导航 |
| 天猫/淘宝全屏通栏背景 | 1920 × 150 | 与现产品占位一致 |
| 无线端店招 | 750 × 200（或 750×254） | 核心信息居中 |
| 京东 PC 通栏 | 约 990～1920 × 150 | 平台略有差异 |
| 美团等本地生活 | 如 692×230 / 750×… | 按模板拆分 |

### B. 模板与素材

| 功能 | 说明 | 代表产品 |
|---|---|---|
| 海量店招模板 | 按行业（茶饮/生鲜/餐饮/服饰…）、风格（国潮/简约/促销…）、节日热点检索 | 创客贴、稿定、图怪兽 |
| 一键套用改字 | 替换店名、slogan、活动文案、价格条 | 全部模板类工具 |
| 版权素材库 | 字体、图标、装饰条、促销贴纸、背景纹理 | 创客贴、稿定 |
| 季节/大促主题包 | 618、双 11、年货节、春茶上市等一键换肤 | 稿定电商分类、创客贴热点模板 |

### C. 编辑与品牌一致性

| 功能 | 说明 | 代表产品 |
|---|---|---|
| 拖拽画布编辑 | 文字/图片/形状图层；对齐、缩放、层级 | 创客贴、稿定、图怪兽、Canva |
| Logo / 品牌色导入 | 上传 Logo、锁定主色，整店视觉统一 | 稿定品牌套件思路；美图风格配方 |
| 字体选择 | 商用字体 + 艺术字效果 | 创客贴、稿定；与魔方「AI 字体」可打通 |
| 多端预览 | PC / 手机店招预览裁切效果 | 部分工具 + 卖家后台预览 |

### D. AI 能力

| 功能 | 说明 | 代表产品 |
|---|---|---|
| 文生图店招 | 输入店名/品类/风格，生成整条横版店招 | 美图设计室、创客贴 AI、稿定 AI |
| 图生图 / 参考图 | 上传现有店招或包装图，改风格/换活动文案 | 创客贴、美图 |
| 智能抠图 / 去背景 | Logo、商品、人物抠出后贴入店招 | 美图、创客贴 |
| 无损改尺寸 / 智能扩展 | 横版拉长、补边，适配 950↔1920 | 创客贴「无损修改尺寸」类 |
| 批量风格统一 | 同一品牌多活动店招统一配色与版式 | 美图「风格配方」思路 |
| AI 文案 | 生成 slogan、活动短句 | 创客贴文生文等 |

### E. 导出与协作

| 功能 | 说明 | 代表产品 |
|---|---|---|
| 多格式下载 | PNG/JPG/PDF；按平台压体积 | 全部 |
| 云端保存 / 历史 | 我的设计、再编辑 | 创客贴、稿定 |
| 分享链接 / 协作 | 同事改字、审稿 | 创客贴 |
| 多端 | Web / App / 小程序 | 创客贴、稿定 |

### F. 非本期主战场（海外实体招牌定制器）

Dezigner / Sign Customiser 等偏**实体发光字/金属字报价 + AR 上墙**，与「电商店铺顶栏」不同。可借鉴点：尺寸精度、材质预览、生产文件导出；**不建议一期照搬报价/AR**。

## 2. 竞品对比结论

| 维度 | 创客贴 / 稿定 / 图怪兽 | 美图设计室 | 魔方智绘（现状） |
|---|---|---|---|
| 定位 | 通用在线设计 + 海量模板 | AI 电商全链路出图 | 农旅县域机构版 · 品牌设计套件 |
| 店招路径 | **模板改字为主**，AI 为辅 | **AI 生图/套图为主**，模板为辅 | 入口在，**能力未上线** |
| 平台尺寸 | 强（按电商场景分类） | 中（偏主图/详情） | 仅 2 个占位尺寸 |
| 品牌资产 | 素材库大 | 风格配方 | **已有 Logo / IP / AI 字体 / 仓库**，未接到店招 |
| 农旅差异化 | 弱（通用模板） | 弱 | **强**（县域特产、产地叙事、已有商拍/IP） |
| 深度编辑 | 强（画布） | 中（工具按钮） | 活动侧已有编辑/深度编辑，店招未复用 |
| 静态无 API 演示 | 依赖云端 | 依赖云端 | 可复用商拍 DEMO 模式 |

**机会点（对魔方）**

1. 不做「又一个 Canva」，做 **农旅电商店招专用台**：茶馆/特产旗舰店/农家乐/文旅店铺模板 + 平台合规尺寸。  
2. **打通已有资产**：仓库 Logo、IP 形象、AI 字体、商拍主图 → 一键铺进店招。  
3. **双通道**：模板套用（快）+ AI 文生/图生（创意）+ 轻量二次编辑（对齐活动）。  
4. 一期只做**线上店招**；实体门头用「效果图预览」弱化，避免印刷/施工报价复杂度。

**风险点**

- 横版超宽（1920×150）文生图易糊字、比例极端，需专用提示词 + 安全区约束 + 必要时「先出氛围底再贴字」。  
- 平台体积限制（约 200KB）与高清出图矛盾，导出需压缩档。  
- 模板版权与运营成本高，一期宜「精选农旅模板 + AI 生成」而非海量素材库。

## 3. 魔方「店招设计」功能方案（建议）

### 3.1 产品定位

**农旅网店店招工作台**：帮县域特产店、茶馆、文旅旗舰店、农家乐等，在数分钟内产出**符合淘宝/天猫/京东等上传规范**的线上店招，并与品牌 Logo / IP / 字体资产联动。

路径：`品牌设计 → 店招设计`（替换「功能建设中」）。

### 3.2 信息架构（建议 UI）

```
左栏                              右栏
┌─────────────────────┐          ┌──────────────────┐
│ 线上店招 | 实体门头(二期灰) │          │ 生成历史 | 参考灵感 │
│ 上架平台（淘宝/天猫/…）   │          │                  │
│ 店招类型（通栏/默认/无线） │          │                  │
│ 店铺名称 *                │          │                  │
│ Slogan / 活动文案（选填） │          │                  │
│ 行业 / 风格预设           │          │                  │
│ 品牌资产：Logo / IP / 字体│          │                  │
│ 参考图（选填）            │          │                  │
│ 尺寸（联动平台，可自定义）│          │                  │
│ 生成数量 1～4             │          │                  │
│ [立即生成店招]            │          │                  │
└─────────────────────┘          └──────────────────┘
```

### 3.3 功能分层（P0 / P1 / P2）

#### P0 · 可上线 MVP（对齐商拍落地节奏）

| 功能 | 说明 |
|---|---|
| 出图方式双通道 | **AI 生成店招**（文生/有 Logo 则图生）+ **套用参考灵感** |
| 上架平台 + 尺寸预设 | 淘宝通栏 1920×150、淘宝 PC 950×120、无线 750×200、天猫通栏、京东通栏、自定义 |
| 必填：店铺名称 | 写入提示词；画面内店名可读 |
| 选填：Slogan、活动信息 | 大促/春茶/开业等 |
| 行业预设 | 茶叶 / 特产生鲜 / 餐饮农家乐 / 文旅景区 / 手作伴手礼 |
| 风格预设 | 新中式 / 国潮 / 清新产地 / 促销爆款 / 简约高级 |
| Logo 上传 / 仓库 | 有 Logo 走图生图保标；无则文生 |
| 参考灵感 | 农旅店招样张（上图下文），套用回填平台尺寸 + 描述 |
| 生成历史 | 进度 + 结果；下载 / 收藏 / 另存；**可选**不做深度编辑 |
| DEMO 离线 | 静态站用本地样张 + 简单 canvas 贴店名演示 |

#### P1 · 差异化增强

| 功能 | 说明 |
|---|---|
| 品牌套件一键带入 | 从 Logo 设计 / IP / AI 字体结果带色板与标准字 |
| 安全区预览 | 画布上叠加「有效区 / 危险边」蒙版 |
| 双端一键出 | 一次生成「PC 通栏 + 无线店招」两张 |
| 智能压图导出 | 导出时可选「平台上传档（≤200KB）」/「高清存档」 |
| 轻量改字 | 复用活动「编辑」能力：改店名、换色条，不重做整图 |
| 节日主题包 | 春茶季、丰收节、年货节等农旅向 |

#### P2 · 延伸

| 功能 | 说明 |
|---|---|
| 实体门头效果图 | 文生「装在建筑立面的门头效果」，尺寸按 cm 换算预览比例 |
| 店招 + 导航条套装 | 同时出导航底条 950×30 |
| 动图 GIF 店招 | 帧数/体积校验 |
| 批量多店 | 县域多子品牌统一换名出图 |

### 3.4 核心交互流程（P0）

1. 选「上架平台 / 店招类型」→ 尺寸自动带出。  
2. 填店铺名称（必填）；选行业与风格；可选 Slogan、Logo、参考图。  
3. 点「立即生成」→ 右侧生成历史进度 → `/api/image` 出图（极端宽高比提示词约束店名清晰、信息居中安全区）。  
4. 下载符合格式的 JPG/PNG；需要改字则进轻量编辑（P1）。  
5. 套用参考灵感：回填描述 + 平台尺寸 + fromCase 跳过二次乱扩写。

### 3.5 提示词原则（草案）

```
横版电商店招，尺寸比例 {{ratio}}，
店铺名「{{shop_name}}」大字清晰可读、置于水平安全区中央，
{{slogan}}，行业：{{industry}}，风格：{{style}}，
左右可有装饰但勿挡店名，适合淘宝/天猫页头，
非海报竖构图，非手机屏幕截图，高清商业设计
+ Logo 参考时：严格保留 Logo 图形与配色
```

### 3.6 与现有模块协同

| 现有模块 | 店招用法 |
|---|---|
| Logo 设计 | 选中 Logo 作为店招角标 / 主标 |
| IP 设计 | 吉祥物小尺寸入画（慎用，避免抢店名） |
| AI 字体 | 店名艺术字生成后合成进店招（P1） |
| 商拍 | 特产主图作店招右侧商品点缀（可选） |
| 仓库 | 统一选图入口 |
| 活动编辑器 | P1 复用改字 / 压图 |

### 3.7 不做清单（一期）

- 不做海量通用素材商城与按次素材计费  
- 不做实体招牌报价、CNC/发光字生产文件、AR 上墙  
- 不做完整 PS 级画布（P0）；P1 仅轻量改字  
- 不与「商拍」抢主图场景——店招专注**店铺顶栏身份条**

### 3.8 成功标准（MVP）

- 用户 3 分钟内产出 1 张可上传淘宝通栏（1920×150）的店招。  
- 店名在预览中可辨认；提供至少 3 个农旅行业参考灵感可套用。  
- 静态 DEMO 环境可完整走通「选尺寸 → 填店名 → 出图 → 下载」。  
- 与 Logo 仓库打通至少「选用已有 Logo」。

## 5. 请你拍板的 3 个问题

1. **一期平台范围**：只做淘宝/天猫通栏 + 无线，还是必须带上京东/美团？  
2. **主路径权重**：更偏「AI 一键生成」还是「精选模板改字」（影响是否先做画布）？  
3. **实体门头**：入口先隐藏，还是保留 Tab 但仅「效果图预览」？

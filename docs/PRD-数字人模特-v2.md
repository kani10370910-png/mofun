## 功能概述

「数字人模特」是面向县域农业宣传、农技推广、政务播报、文旅推介、电商带货等场景的**单人口播数字人视频生成器**。用户选择或创建一个数字人形象、填写配音文案、挑选音色，一步产出该形象「对口型说话」的口播视频；可对形象抠图换背景、用「商品图合成」把货品融进人物手中，并把口播文案按句烧成随声出现的字幕——全部在浏览器端合成。

与「制作大片」「一句话生成视频」的区别：

| 维度 | 数字人模特 | 制作大片 | 一句话生成视频 |
|---|---|---|---|
| 产物 | 单人口播视频（形象+配音对口型）| 多镜头长视频（最多 150 镜）| 单段 5–15s 视频 |
| 主体 | 固定数字人形象出镜说话 | 多角色/场景/道具叙事 | 无固定主体 |
| 驱动 | 文案 → TTS 音频 → 音频驱动口型 | 文本/首尾帧驱动画面 | 一句话驱动画面 |
| 换背景 | 客户端 RVM 抠像 + 背景合成（图片/视频）| 无 | 无 |
| 输出比例 | 跟随人像图片自身比例 | 全局视频比例（7 选 1）| 视频比例（含智能）|

核心能力：
- **形象库**：内置官方农旅形象 +「我的形象」（AI 生图 / 本地上传 / 仓库选图创建），点击即用。
- **AI 生成形象**：性别/年龄/肤色 + 角色描述（可 AI 优化）→ 文生图产出正面清晰人像。
- **抠图换背景**：上传/生成后**点按钮才抠图**（真人走 RVM、卡通走漫填充、兜底用原图），抠出人像叠到静态图 / 动态视频背景，支持人像大小/左右、背景位置微调。
- **商品图合成**：把第二张图（商品/道具）的元素按文字描述融进形象原图，结果作为新的形象图（Seedream 多图参考）。
- **配音**：火山 TTS 多音色 + 语速/音量/语调/情感调节 + 声音复刻（用自己的声音）。
- **随声字幕**：口播文案按句切成短句、随语音逐句烧进画面底部，可开关。
- **对口型出片**：文案 → TTS → 数字人模型（火山 OmniHuman1.5 默认 / wan2.2-s2v 兜底）音频驱动人像说话，结果进「生成历史」。
- **本地持久化**：我的形象 / 我的背景 / 生成历史（元数据 localStorage + 视频 blob IndexedDB），刷新不丢。
- **线上 DEMO 兜底**：静态导出无后端时，全模块用纯客户端假数据跑通（见 §10）。

## 全局生成设定（主面板）

主面板从上到下为一条竖向配置流：

| 区块 | 必填 | 类型 | 可选值 / 默认 | 说明 |
|---|---|---|---|---|
| 数字人形象 | 是 | 预览框 +「形象库」| — | 固定预览框；选官方形象或我的形象，绑背景则显示合成预览 |
| 配音内容 | 是 | 多行文本 | ≤ 500 字 | 让数字人说的话；实时估算时长（约 3 字/秒）|
| 选择音色 | 是 | 弹窗选择 | 默认「跟随形象默认」·1.0x | 火山音色 + 语速/音量/语调/情感 + 声音复刻 |
| 角色表现 | 否 | 多行文本 | — | 动作/情绪/运镜提示词，作对口型模型文本引导（可「随机」）|
| 字幕 | 是 | 分段按钮 | **显示**（默认）/ 隐藏 | 是否把口播文案按句烧进画面底部 |
| 生成模式 | 是 | 分段按钮 | **720p**（默认）/ 1080p，均 30FPS | 对口型输出分辨率档位 |
| 生成数量 | 是 | 分段按钮 | **1**（默认）/ 2 | 一次生成的条数 |

> **输出比例**：本模块**不设「视频比例」选择器**——最终视频比例**跟随所选人像图片自身比例**（竖图出竖版、横图出横版）；换背景 / 人像缩小时仍按同一画幅输出。

## 1. 数字人形象（形象库）

「形象库」弹窗分两个 Tab：**官方形象**、**我的形象**，顶部按角色定位筛选。

### 1.1 官方形象

内置官方农旅主题形象，字段定义见 `src/data/avatars.ts › AvatarPreset`。

| id | 名称 | 角色定位 | 性别·年龄 | 默认音色 | 特点 |
|---|---|---|---|---|---|
| av1 | 文旅小帅 | 景区导游 | 男·青年 | 京腔侃爷 | 半身像，自带农旅场景，悬停播 demo |
| av2 | 田园阿芳 | 农技推广 | 女·中年 | 邻居阿姨 | 稻田实景全身像，悬停播口播 demo 视频 |

- **点击即用**：鼠标移入卡片高亮描边并播放 demo 口播视频（`demo` 字段，有则播）、移出显示封面图；**点击卡片主体 = 直接选用**并关闭形象库，无独立「使用」按钮。
- **编辑背景**：官方形象仅可改背景、不可改形象图（图片锁定）；另有查看大图入口。
- **角色定位筛选**（`AVATAR_ROLES`，标签保留全量以便扩展）：全部 / 景区导游 / 农技推广 / 品牌代言 / 官方播报 / 乡村主播 / 文化传播 / 带货主播 / 科普讲解。

### 1.2 我的形象（MyAvatar）

用户创建的可复用形象，字段见 `AvatarEditor.tsx › MyAvatar`。

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| id | — | string | `ma_*` |
| name | 是 | string | 形象昵称（≤ 16 字）|
| img | 是 | string | 人像图（data URI / 本地路径）；**仅限清晰人物照片，拒绝视频/场景图** |
| scene | 否 | string | 角色定位标签 |
| performance | 否 | string | 角色表现（选用时回填）|
| voiceId / speed / emotion | 否 | — | 绑定音色与参数（选用时回填）|
| bg | 否 | AvatarBgCfg | 绑定在形象上的背景：有则「换背景」合成，无则原图 |

三种创建入口，统一进「创建我的形象」弹窗填写后入库：
- **AI 生图**：见 §1.3。
- **本地上传**：≤ 10MB 的 jpg/png/webp；**校验拒绝视频**（`file.type` 非 image 时提示「人像请上传清晰的人物照片」）。
- **从仓库选择**：仓库里有真实图片的作品/素材；选人像时排除视频作品（其封面非清晰人像）。

### 1.3 AI 生成形象（AI 生图弹窗）

| 字段 | 必填 | 可选值 / 默认 | 说明 |
|---|---|---|---|
| 性别 | 是 | 女（默认）/ 男 | |
| 年龄 | 是 | 青年（默认）/ … | `AG_AGE_WORDS` 映射 |
| 肤色 | 否 | 滑块 | `AG_SKIN_WORDS` 映射 |
| 角色描述 | 是 | 多行文本 | 支持 **AI 优化**（`/api/avatar-desc`）与一键清空 |
| 比例 | 是 | 9:16（默认）/ 16:9 / 3:4 / 4:3 / 1:1 / 3:2 / 2:3 / 21:9 | `ratioToSize` 映射像素（目标约 4MP、64 对齐）|

- 生图提示词（`aiGenerate` 本地拼装）：`数字人形象，{性别}性，{年龄}，{肤色}，{角色描述}，正面清晰面部，专业摄影棚布光，写实人像，高清`。

## 2. 创建 / 编辑形象弹窗

上传/AI 生图/仓库选图后进入本弹窗（三栏布局：左「背景选择」+ 右「原图 / 处理区」）。右侧原图区提供三个动作按钮：**开始抠图**、**商品图合成**、以及从左侧选背景后的换背景合成。

### 2.1 抠图（点按钮才抠）

- **不自动抠**：上传 / 生成后先显示原图 + 「开始抠图」按钮，**用户点击后才抠**（`matteStarted`）；抠像过程有扫描线动效（`MattingScan`），完成后在透明棋盘格上显示抠出的人像（`CutoutPreview`），可「重新抠图 / 用原图」。
- **智能路由抠像**（`matteAuto`）：
  | 图像类型 | 判定 | 抠法 |
  |---|---|---|
  | 真人照片 | 非透明占比在 0.1–0.9 之间 | RVM 逐帧抠像（`rvm_mobilenetv3_fp32.onnx`）|
  | 卡通 / 插画 | RVM 会误erase | 边角同色**漫填充**（`matteFlatBg`：从四角泛洪去平底色 + 羽化）|
  | 兜底 | 上两者都不理想 | 保留原图不透明（`opaqueCanvas`，**绝不输出全透明空图**）|
- **缓存**：抠像结果按图源缓存（`getMatteCached / hasMatteCached`），预览、编辑器、生成共用，重复操作不重算。

### 2.2 商品图合成

把第二张图（商品/道具）里的元素，按文字描述融进形象原图，结果作为新的形象原图（可继续抠图 / 换背景 / 保存）。

| 输入 | 说明 |
|---|---|
| 图 1（原图）| 当前形象图，主体人物 |
| 图 2（参考图）| 用户上传的商品/道具图（≤ 10MB，jpg/png/webp）|
| 描述 | 如「把图 2 中的茶杯放到图 1 人物的手上」（≤ 200 字）|

- 走 `/api/image` 多图参考（Seedream 系列），`image: [图1, 图2]` + 合成提示词（要求保持人物相貌/服饰/构图不变，自然融合光影透视）。
- **出图尺寸**：按图 1 宽高比取总像素 ≈ 2048²（约 4.19M）、64 对齐，稳过 Seedream「≥ 3686400 像素」下限，且不把人像拉变形。
- 结果趁新鲜转 data URI 持久化后回填为新原图。

### 2.3 背景选择与换背景

左栏「背景选择」三个来源（`cBgSub`）：**图片 / 视频 / 自定义**。

- **图片**：内置背景库（`AVATAR_BG_PRESETS`），分类 **全部 / 演播室 / 农业 / 文旅**（无纯色）；网格为**瀑布流按原比例展示、上下滑动**。
  - 农业分类含各比例背景（模型生成）：9:16 / 16:9 / 3:4 / 4:3 / 1:1 / 3:2 / 2:3 / 21:9 共 8 张，配合不同人像比例。
- **视频**：动态背景（`dyn` 视频）。
- **自定义**：AI 生成背景（`aiGenerateBg`）/ 本地上传（图片或视频，视频抽首帧作封面）/ 从仓库选择。
- **原图背景**：不换背景，输出即人物自带场景。

### 2.4 位置调整（`AvatarBgCfg`，拖动实时预览）

| 参数 | 范围 | 说明 |
|---|---|---|
| 人像大小（personScale）| 0.4 ~ 1 | 1 = 填满画面 |
| 人像左右（personX）| -1 ~ 1 | 仅 personScale < 0.99 时可移动 |
| 背景位置（bgOffsetY）| -1 ~ 1 | 作用于有溢出的那个轴（竖向有余量→上下移，否则→左右移）|

- **AI 生成背景**（`/api/image`）提示词：`数字人视频背景场景，{描述}，农文旅主题，横向宽幅构图，画面中无人物、无文字，景深虚化留出人物站位，专业布光，写实高清`。
- **动态背景生成**（`/api/video` · seedance-2.0-mini · 720p · 5s）提示词：`{描述}。保持画面构图基本稳定，动态轻微自然，画面中没有人物、没有文字，作为数字人口播的背景`。

## 3. 配音（音色与声音复刻）

### 3.1 音色与参数

| 参数 | 范围 | 默认 | 发送处理 |
|---|---|---|---|
| 音色（selectedVoice）| `VOICES` 库 | 跟随形象默认（`defaultVoice`）| 火山 `voice_type` |
| 语速（speed）| 0.5 – 2 | 1.0 | 直接下发 |
| 音量（volume）| 1 – 10 | 5 | 下发时 `/5` 归一 |
| 语调（pitch）| 0.5 – 2 | 1.0 | 直接下发 |
| 情感（emotion）| 多情感音色可选 | 中性 | `VOLC_EMOTION` 映射，仅 `multiEmotion` 音色生效 |

- 音色选择弹窗与「制作大片」一致：系统 / 收藏 Tab + 场景 / 年龄 / 性别筛选。

### 3.2 声音复刻（与制作大片共用）

录制或上传一段约 10–20s 的清晰中文朗读 → 训练成专属音色（`S_` 前缀 speakerId）。
- 前端统一转 WAV 上传 → `/api/voice-clone`（action:`train`）→ 轮询 `status`。
- 复刻音色在生成时以 `clone: /^S_/.test(voice)` 标记走克隆通道。

## 4. 角色表现（可选）

选填的动作 / 情绪 / 运镜提示词（如「沉稳专业，神态从容，讲到重点时微微挑眉强调」），非空时作为对口型模型的文本引导；提供「随机」按钮填入预设。生成失败时会自动重试并去掉该文本以排除干扰。

## 5. 随声字幕

口播文案按句切成短句、随语音逐句烧进画面底部，默认开启、可关闭；生成与刷新恢复共用同一套切分。

- **分句规则**（`buildAvatarCues`）：先按句末标点（。！？；换行）分句；过长的句子再按逗号（，）→ 顿号（、）→ 字数逐级切成 ≈ 20 字的短句，避免一句字幕堆满画面、末尾被「…」截断。
- **时间轴**：按各短句字数占比分配时长（依据 TTS 真实内容时长），到点显示对应短句、随声逐句切换。
- **烧录**（`drawCaptionAt`）：画面底部暗角护底 + 白字描边，任意背景可读；换背景合成与无背景直出两条链路都过一遍 canvas 把字幕烧进画面（`burnCaptionsOnVideo`）。

## 6. 立即生成与出片

### 6.1 生成设定

- **生成模式**：720p（默认）/ 1080p，30FPS——对应对口型模型 `resolution`。
- **生成数量**：1（默认）/ 2。

### 6.2 生成管线（`generate`）

```
校验（有形象 + 有文案 + 时长合规）
  → TTS 合成音频（synthTTS，坏音频自动重试）+ 真实时长校验
  → 规范化人像图（normalizeS2vImage：本地/远程/AI 图统一 ≤1280 JPEG）
  → 对口型出片（OmniHuman1.5 默认 / wan2.2-s2v 兜底，原图出片、人物清晰）
  → 字幕：按口播文案分句烧录（开关开时）
  → [绑背景?] 换背景合成（RVM 两遍抠像，见 §7）/ 否则直出（比例=人像图片自身比例）
  → 存 IndexedDB + 进生成历史 + 存入「我的作品」
```

- **文案时长**：`estSec ≈ ceil(字数/3/语速)`，超上限即拦截。
- **提交超时**：前端 `AbortSignal.timeout(450s)`（wan2.2 阻塞式出片最长约 7 分钟）。
- **换背景音轨**：合成时前景静音（规避自动播放拦截），口播音轨改经 Web Audio（`AudioContext` 在点击手势内 resume）注入。

## 7. 换背景合成（RVM 客户端抠像）

替代绿幕 chroma-key 的核心能力：对口型用**原图**出片（清晰无绿边），再在浏览器端把人物抠出来叠到新背景。

### 7.1 技术栈

| 组件 | 说明 |
|---|---|
| 模型 | RVM（Robust Video Matting，`rvm_mobilenetv3_fp32.onnx`，14MB，`public/models`）|
| 运行时 | `onnxruntime-web`，**WASM EP**（WebGPU 因 AveragePool ceil_mode 不支持而禁用）|
| 多线程 | `crossOriginIsolated` 时 `numThreads=min(8,cores)`，否则单线程；需 nginx 配 COOP/COEP 头 |

### 7.2 两遍式合成（`compositeMatteOverBg`）

- **Pass1（离线抠像）**：逐帧 seek 视频 → RVM 抠 alpha → 缓存（裁到 alpha 包围盒定位）。
- **Pass2（实时合成）**：静音播放前景 + Web Audio 注入口播音轨 + `requestAnimationFrame` 逐帧绘制（背景 cover + 人像 contain-bottom，按 `personScale/personX/bgOffsetY`）+ 字幕烧录 + MediaRecorder 录制；到口播时长即停（截掉尾部冻结帧）。
- **动态背景**：`bg.dyn` 存在时背景为视频，否则静态图；先缓冲成 blob URL 再解码，避免流式解码卡顿。

> Chrome 对后台标签页会节流 rAF，Pass2 在后台标签页会停滞（仅自动化测试环境限制，真实可见浏览器正常）。

## 8. 对口型接口（`/api/lipsync`）

两个提供方，由 `LIPSYNC_PROVIDER` 选默认、`LIPSYNC_ALLOW_FALLBACK` 控回退：**omnihuman**（火山即梦 OmniHuman1.5，默认）/ **dashscope**（阿里云百炼 wan2.2-s2v，兜底）。OmniHuman 提交失败时**默认自动回退 wan2.2 出片**（`LIPSYNC_ALLOW_FALLBACK=0` 则纯 OmniHuman 不回退）。

### 8.1 OmniHuman1.5（火山引擎视觉智能 · 默认）

- **接入**：`visual.volcengineapi.com`，service `cv`，region `cn-north-1`，AK/SK V4 签名（`src/lib/volcSign.ts`）。
- **管线**：提交 `CVSubmitTask`（`req_key=jimeng_realman_avatar_picture_omni_v15`，体含 image_url / audio_url / prompt / resolution）→ 轮询 `CVGetResult` → `data.video_url`。
- **输入**：图片 + 音频 +（可选）prompt（角色表现 ≤ 300 字）；分辨率 1080P / 720P。
- **约束**：音频 < 60s（建议 ≤ 15s）；并发 1；计费按秒。
- **依赖**：控制台开通「OmniHuman1.5」+ `VOLC_ACCESS_KEY` / `VOLC_SECRET_KEY`；图片/音频需公网可访问 URL（火山视觉支持 `binary_data_base64` 直传图片字节以免托管）。
- **当前落地状态**：所用账号该视觉服务尚未开通（提交返回 `Access Denied`），故实际出片当前走 wan2.2 兜底；待控制台开通即可切回。

### 8.2 wan2.2-s2v（阿里云百炼 · 兜底）

- **管线**：申请上传凭证 → 图/音频上传百炼 OSS（`oss://`，免火山 TOS）→ 提交 `image2video/video-synthesis` → 轮询至 SUCCEEDED → `video_url`。
- **音频后缀归一**：火山 TTS 返回 `audio/mpeg`，s2v 只认 `.wav/.mp3`，上传前归一。
- **失败自动重试**：FAILED / UNKNOWN 时退避 3s 自动重试 1 次并去掉 `text`。
- **约束**：单次输入音频 ≤ 20s；密钥 `DASHSCOPE_API_KEY`。

## 9. 数据结构、持久化与 API

### 9.1 持久化

| 数据 | 存储 | 键 / 说明 |
|---|---|---|
| 我的形象 | localStorage | `mofun.avatar.myAvatars`（MyAvatar[]）|
| 我的背景 | localStorage | `mofun.avatar.myBgs`（MyBg[]，视频背景过大可能超配额）|
| 生成历史元数据 | localStorage | `mofun.avatar.runs`（AvatarRun 精简元数据）|
| 生成视频 blob | IndexedDB | `getCachedVideo/putCachedVideo`（刷新后秒开/可下载）|
| 未完成任务 | localStorage | `mofun.avatar.pending`（taskId + 合成参数，刷新/断线后接着轮询）|
| 官方形象临时背景 | 内存态 | `presetBg`（仅当前选中形象，去使用设置，不持久化）|

### 9.2 API 路由总览

| 路由 | 方法 | 用途 | 模型 / 依赖 |
|---|---|---|---|
| `/api/tts` | POST | 文案 → 口播音频 | 火山 TTS |
| `/api/lipsync` | POST | 音频 + 人像 → 对口型视频（submit / status）| 火山 OmniHuman1.5（默认）/ 百炼 wan2.2-s2v（兜底）|
| `/api/image` | POST | AI 生成形象 / 背景 / 商品图合成（多图参考）| 文生图（Seedream 等）|
| `/api/avatar-desc` | POST | 角色描述 AI 优化 | LLM |
| `/api/video` | POST | 动态背景生成（i2v）| Seedance 2.0 Mini |
| `/api/voice-clone` | POST | 声音复刻（train / status）| 火山声音复刻 |
| `/api/proxy-image` · `/api/proxy-video` | GET | 跨域图片/视频代理（抠像/合成防跨域）| — |

## 11. 关键约束速查

| 项 | 值 |
|---|---|
| 主流程 | 选形象 → 填文案 → 选音色 →（可选角色表现/字幕/换背景）→ 立即生成 |
| 官方形象 | av1 文旅小帅（半身）、av2 田园阿芳（全身），点击即用，可编辑背景（图锁定）|
| 我的形象 | AI 生图 / 上传 / 仓库创建；人像槽仅收清晰人物照片（拒视频/场景图）|
| 抠图 | 点「开始抠图」才抠；真人 RVM / 卡通漫填充 / 兜底原图；结果缓存复用 |
| 商品图合成 | 图1 + 图2 + 描述 → Seedream 多图；出图尺寸按比例 ≥ 3686400 像素 |
| 背景 | 分类 演播室/农业/文旅（无纯色）；农业含 8 种比例背景；瀑布流上下滑动；图片/视频/自定义 |
| 输出比例 | 跟随人像图片自身比例（无「视频比例」选择器）|
| 字幕 | 默认显示；长句按逗号/顿号/字数切 ≈20 字短句，随声逐句烧录，可关 |
| 生成模式 | 720p（默认）/ 1080p · 30FPS |
| 生成数量 | 1（默认）/ 2 |
| 配音 | ≤ 500 字；语速 0.5–2 / 音量 1–10 / 语调 0.5–2 / 情感（多情感音色）|
| 数字人模型 | 火山 OmniHuman1.5（默认，待账号开通）/ wan2.2-s2v（默认自动回退出片）|
| 换背景 | RVM 客户端抠像两遍合成；图片/视频背景 + 人像大小/左右/背景位置 |
| 存储 | localStorage（形象/背景/历史元数据/未完成任务）+ IndexedDB（视频 blob）|
| 部署 | 静态导出 `out/` → 内网 Nginx `.../html/out`（`deploy_code_tar.py`）|

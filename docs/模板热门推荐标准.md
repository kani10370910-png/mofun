# 模板库 · 热门推荐标准

> 适用范围：创作中心 → **模板** 页「🔥 热门推荐」区块  
> 关联代码：`src/data/templates.ts`、`src/components/template/TemplateView.tsx`  
> 更新日期：2026-08-05

---

## 1. 区块定位

「热门推荐」是模板库首页的**首屏精选区**，在用户选择场景 / 类型 / 分类筛选之前或之后，优先展示一批**值得优先尝试**的模版，帮助用户：

- 快速找到高质量、可套用的灵感起点；
- 覆盖区县文旅、农产品、电商等典型业务场景；
- 降低「空白表单不知填什么」的使用门槛。

与「全部模版」的区别：

| 维度 | 热门推荐 | 全部模版 |
|------|----------|----------|
| 入选方式 | 运营白名单（见下文） | 灵感全量 + 精选合并后的完整列表 |
| 展示顺序 | 独立区块，置顶 | 热门项也会出现在下方（带 🔥 角标） |
| 数量 | 随筛选变化，最多等于白名单命中数 | 全量 |
| 排序 | 合并列表内「热门优先」，区块内按数据层排序 | 热门优先 → 类型（品牌设计 / 文案 / 视频）→ 名称 |

## 2. 当前实现（代码事实）

### 2.1 数据来源

模版库数据由两部分合并：

1. **灵感全量**：各创作模块「参考灵感」自动同步（`templatesFromInspiration()`）
2. **精选模版**：`featuredTemplates` 中场景化命名、定制封面与 `fill` 的条目

合并规则（`mergeTemplates`）：以「类型 + 分类 + 名称」为唯一键，精选覆盖同名灵感项的封面与回填字段。

### 2.2 热门标记机制（现行）

**热门与否不由使用量自动计算**，而是由 `templates.ts` 中的 **`HOT_PICKS` 白名单** 决定：

```typescript
// 仅名称完全匹配的模版会被标记 hot: true
const HOT_PICKS: { name: string; uses: string }[] = [ ... ];

function applyHotPicks(list) {
  // 命中白名单 → hot: true，并覆盖 uses 展示值
  // 未命中 → 强制 hot: false（含 featuredTemplates 里曾手写 hot: true 的项）
}
```

要点：

- 匹配字段：**模版名称 `name` 字符串完全一致**
- `featuredTemplates` 内的 `hot: true` 在导出前会被置为 `false`，**不生效**
- 展示用的「看过人数」`uses`：白名单条目用 `HOT_PICKS` 中的值；非热门灵感项用算法模拟值（`180 + 序号偏移`，非真实统计）

### 2.3 前端展示规则

`TemplateView.tsx`：

```typescript
const hot = templates.filter((t) => t.hot && match(t)); // 同时满足筛选条件
```

- 区块标题：**🔥 热门推荐**（仅当 `hot.length > 0` 时渲染）
- 卡片角标：`hot === true` 时显示 **🔥 热门**
- 筛选联动：切换场景 / 类型 / 分类后，热门区**只展示仍符合筛选条件**的白名单模版
- 若当前筛选下无热门命中：隐藏热门区块，仅显示「全部模版」

## 3. 产品标准（推荐执行）

以下为建议的**运营 + 产品标准**，可在接入真实埋点后逐步自动化。

### 3.1 入选原则（须同时满足）

1. **质量可用**  
   - 封面清晰、与模版内容一致；  
   - 套用后表单回填完整，生成结果可接受（经模块负责人或设计验收）。

2. **代表性强**  
   - 能代表某一**场景 × 类型 × 分类**的典型用法；  
   - 优先区县业务：农产品、文旅、节庆、电商、政策科普等。

3. **差异覆盖**  
   - 同一「类型 + 分类」不宜重复堆叠过多相似模版；  
   - 同一 IP / 同一活动系列最多保留 1～2 条热门。

4. **时效适当**  
   - 强季节模版（如「明前白茶」）可在对应季节上调；  
   - 过时活动模版应移出热门或替换。

5. **合规与安全**  
   - 无侵权素材、无敏感政治/虚假宣传表述；  
   - 政策科普类须与现行文件表述一致。

### 3.2 量化参考（有真实数据后启用）

在尚未接入统计前，**以人工白名单为主**；接入「详情浏览 / 套用点击」埋点后，可按以下阈值辅助提名：

| 指标 | 建议阈值 | 说明 |
|------|----------|------|
| 近 30 日套用次数 | ≥ 全库 Top 15% | 主排序依据 |
| 近 30 日详情打开率 | ≥ 20% | 排除「标题党、效果差」 |
| 套用后完成生成率 | ≥ 60% | 保证模版真正好用 |
| 用户评分 / 反馈 | 无集中差评 | 有反馈渠道后启用 |

**冷启动阶段**（当前）：由运营按 3.1 原则人工挑选，不强制满足上表数值。

### 3.3 数量与结构

| 规则 | 建议值 |
|------|--------|
| 白名单总量 | **8～12 条**（当前 10 条，合理） |
| 类型分布 | 品牌设计 4～5、文案策划 2～3、视频宣传 2～3 |
| 场景分布 | 至少覆盖 4 个以上场景标签，避免全部落在「电商推广」 |
| 单分类上限 | 同一 sub（如「AI字体」）热门不超过 **3 条** |

### 3.4 更新节奏

| 动作 | 频率 |
|------|------|
| 例行复核 | 每 **双周** 检查一次白名单与封面/回填是否仍有效 |
| 大促 / 节庆 | 节前 **7 天** 替换 2～4 条季节向模版 |
| 新模块上线 | 上线后 **3 个工作日内** 至少加入 1 条热门样例 |
| 紧急下架 | 发现侵权、错误政策表述等 **24 小时内** 从 `HOT_PICKS` 移除 |

### 3.5 展示字段标准

| 字段 | 标准 |
|------|------|
| `name` | 与灵感源名称一致，便于白名单匹配；用户可读，≤ 20 字为宜 |
| `uses` | 有真实统计前：手工填写合理区间（200～2.3k）；有统计后：取近 30 日详情 UV 或套用次数，格式 `986` / `1.2k` / `1.5万` |
| `hot` | 仅白名单条目为 `true`，由 `applyHotPicks` 统一写入，不在 `featuredTemplates` 手写 |
| 角标 | 仅热门卡片展示「🔥 热门」，全部列表中同步展示 |

## 4. 运营操作流程

### 4.1 新增热门

1. 在对应创作模块确认灵感条目已存在且 `name` 唯一。  
2. 编辑 `src/data/templates.ts` → `HOT_PICKS`，追加 `{ name, uses }`。  
3. 本地打开 `/template`，确认：  
   - 默认筛选下出现在「热门推荐」；  
   - 套用后跳转与表单回填正确。  
4. 若总量超过 12 条，按 3.3 结构淘汰最弱一条。

### 4.2 移除热门

从 `HOT_PICKS` 删除对应行即可；无需改 `featuredTemplates`。

### 4.3 改名注意

**白名单按名称精确匹配**。若灵感或精选模版改名，必须同步更新 `HOT_PICKS` 中的 `name`，否则将失去热门标记。

## 5. 筛选与用户体验

- 用户选择「场景 = 农产品」时，仅展示 `scene === "农产品"` 的热门项（如「茶灵儿 IP 形象」）。  
- 用户选择「类型 = 文案策划」时，若白名单无文案类条目，**热门区块不显示**——属预期行为，也反映当前白名单需补全文案/视频类热门。  
- 「看过人数」当前为展示用数据，Tooltip 文案为「多少人看过」；接入统计后应改为真实 UV 或改为「多少人套用」并统一文案。

## 6. 演进路线

| 阶段 | 目标 | 实现要点 |
|------|------|----------|
| **V1（当前）** | 人工白名单 | `HOT_PICKS` + `applyHotPicks` |
| **V2** | 半自动 | 后台配置热门 ID 列表，或按 `uses` 真实排序取 Top N |
| **V3** | 全自动 + 个性化 | 按区县、账号行业、季节加权；A/B 测试热门位 |

V2 起建议：

- 废弃名称字符串匹配，改用稳定 `templateId`；  
- `featuredTemplates` 与灵感项统一 ID；  
- 热门区块支持「不足 N 条时用次热补位」规则。

## 7. 验收清单

发布前确认：

- [ ] `HOT_PICKS` 每条 `name` 在合并后的 `templates` 中存在且唯一命中  
- [ ] 品牌设计 / 文案策划 / 视频宣传覆盖符合 3.3（或产品签字豁免）  
- [ ] 至少 4 个场景标签有热门代表  
- [ ] 全部热门模版「套用模版」跳转与回填正确  
- [ ] 切换各筛选组合无报错；无热门时区块正确隐藏  
- [ ] 详情弹窗「标记：热门推荐」仅对白名单项展示

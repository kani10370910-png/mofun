# 制作大片 · 功能异常场景规范

适用范围：视频宣传 → 制作大片（Studio）模块，含 ①脚本编辑 / ②角色场景道具 / ③分镜制作 / ④视频预览 四步流程  
文档用途：前端异常处理实现参考

---

## 一、输入校验类

### ① 脚本编辑

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 一句话输入为空 | 未填写一句话即点「生成脚本」 | toast 提示："先用一句话说说：类型 + 故事"；不发起生成 |
| 脚本为空就进下一步 | 右侧脚本框为空，点「下一步」或「完成」 | toast 提示："先用左侧一句话生成镜头脚本，或粘贴/上传剧本"；不进入②分镜 |
| 上传剧本文件超大 | 上传 .txt / .docx 文件超过 10 MB | 文件选择后立即拦截，toast 提示："文件不能超过 10MB" |
| 上传剧本格式为 PDF | 上传 .pdf 文件（无法直接解析） | toast 提示："PDF 请先转成 TXT/DOCX，再上传"；不解析内容 |
| 脚本包含敏感词 | 脚本文本命中本地敏感词库 | 编辑框内高亮敏感词段落；不拦截流程，仅提示；生成视频时在后端二次拦截 |

### ② 角色场景道具

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 参考图格式不合规 | 上传元素参考图扩展名不在白名单（仅允许 JPG / PNG / WEBP） | 文件选择器已用 `accept="image/jpeg,image/png,image/webp"` 限制；拖拽上传需 JS 二次校验，命中非白名单立即拦截，toast 提示："仅支持 JPG、PNG、WEBP 格式图片" |
| 参考图体积超限 | 上传元素参考图文件体积超过 10 MB | 文件选择后立即拦截，toast 提示："图片大小不能超过 10 MB，请压缩后重试"；不进入预览流程 |
| 一键生成图片时无元素 | 元素列表为空时点「一键生成全部图片」 | toast 提示："请先添加角色/场景/道具元素" |

### ③ 分镜制作

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 无分镜就点全部生成 | 镜头列表为空时点「全部生成视频」 | toast 提示："请先在①脚本编辑生成镜头脚本"；不进入生成流程 |
| 非顺序生成（跨镜跳生成） | 前面某镜未完成（非 done）时点后面的镜头「生成」 | toast 提示："请先按顺序生成前面的镜头"；不启动本镜生成 |
| 智能多帧模式缺镜头图 | 生成模式为「智能多帧」但本镜 `firstFrame` 为空，点「生成本镜」 | 该镜置为失败态，failReason："本镜还没有镜头图，请先点「生成全部镜头图」或单镜「AI 生成」"；toast 同步提示 |
| 编辑视频但本镜无视频 | 点「编辑视频」但该镜 `videoUrl` 为空 | toast 提示："这一镜还没有视频，无法编辑" |
| 编辑视频内容为空 | 弹出「编辑视频」对话框但未填写修改要求即确认 | toast 提示："请填写要修改的内容" |

### ④ 视频预览 / 导出

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 无已生成分镜就导出 | 无任何 `status=done` 的镜头时点「导出长视频」 | toast 提示："请先在「分镜脚本」拆出镜头"；不启动录制 |

## 二、AI 脚本生成类（Step ①）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 完整脚本生成失败 | `/api/generate`（scene=`studio-script-pro`）返回非 200 或 body 为空 | toast 提示："生成失败，请重试"；脚本框保留空白；生成按钮恢复可点 |
| 镜头摘要生成失败 | 二段式生成第一步（scene=`studio-summary`）返回空文本 | toast 提示："镜头摘要生成失败，请重试"；不进入第二步镜头生成；按钮恢复 |
| 完整镜头生成中断 | 第二步（scene=`studio-shots`）fetch 异常（网络中断、超时） | toast 提示："生成中断，请重试"；脚本框保留已流式回填的部分内容，不清空 |
| 重复点击生成（防抖） | `busy=true` 时再次点「生成脚本」 | 按钮置灰（`disabled`），点击无响应；不重复发起请求 |
| 脚本生成后分镜拆分结果为空 | 脚本内容无可识别的镜头段落（`splitShotBlocks` 返回空数组） | toast 提示："脚本里没找到可拆分的镜头，试试修改格式或重新生成"；不进入③ |

## 三、元素参考图生成类（Step ②）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| AI 描述扩写失败 | 单个元素无 `desc`，调 `/api/generate`（scene=`studio-asset-desc`）失败 | 静默降级：用元素名称作为生图描述继续；不弹错误、不中断整批生成 |
| 单个元素图片生成失败 | `/api/image` 返回错误或 `images` 为空 | 跳过该元素（无报错），`done++`；完成后 toast 汇总："已为 N/M 个元素生成参考图"；N < M 时改为 warn 样式 |
| 全部元素生成失败 | 所有 `/api/image` 调用均无图片返回 | toast（warn）提示："生成失败，请重试（检查图片模型配置）" |
| 用户停止一键生成 | 点「停止」按钮，或切换步骤触发 abort | 立即中止所有在飞请求（`genImgAborts` 全部 abort）；toast 提示："已停止，已生成 N/M 个（其余保留未生成，可再次点一键生成继续）"；按钮恢复可点 |
| 并发上限 | 同时超过 3 个生成请求 | 内部队列控制，最多 3 并发，不向用户暴露；排队中的元素静默等待 |
| 参考图预览加载失败 | 图片 `onError`（URL 失效 / 跨域） | 卡片回退到默认占位（灰底 + 图标），可重新点击上传 |

## 四、逐镜视频生成类（Step ③）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 单镜生成超时 | `/api/video` 请求超过前端 450s 窗口（`AbortSignal.timeout(450_000)`），或网关返回 HTTP 504 | 该镜置为失败态（`status=failed`，`pct=0`），展示 failReason："生成超时（视频耗时过长），请重试" |
| 网络异常（fetch 抛出） | `/api/video` 的 `.catch` 捕获网络错误（非 TimeoutError） | 该镜置为失败态，failReason："网络异常，请重试" |
| 模型生成失败 | `/api/video` 返回非 2xx 或 `videoUrl` 为空 | 该镜置为失败态，展示 `mapVideoErr` 映射的中文原因（见下方映射表）；生成按钮变「重试」 |
| 生成结果为空（无 videoUrl） | 请求成功但响应中无可用 `videoUrl` | 与「模型生成失败」同处理：置失败态，展示兜底文案；不展示空白播放器 |
| 审核拦截（输入图片） | 参考图/元素图片命中内容审核，`error` 含 image / 图 | failReason："输入图片未通过审核：某个元素参考图被判敏感（常见：斧头/刀具等被误判为「武器」，或某张图触发审核）。改文字无效——去③取消本镜绑定该元素后重试（网关原文：…）"；`去改写` 按钮不处理此类失败，需提示用户取消该元素绑定 |
| 审核拦截（文字描述） | 画面描述命中内容审核，`error` 含 text / prompt / 文 | failReason："画面描述文字未通过审核，请修改文字（点「去改写」）"；展示「审核失败·AI 改写重试」按钮，点击调 `/api/generate`（scene=`studio-safe-rewrite`）改写后自动重新生成 |
| 审核拦截（类型不确定） | 同时含 content/safety 但无法区分文字/图片来源 | failReason："内容未通过审核：可能是文字，也可能是输入图片（人物/元素参考图、上一镜尾帧）。若改文字无效，多为图片被判敏感" |
| 真人首帧隐私审核拦截 | 首帧图含真人正脸，被 Seedance 隐私审核拦截 | failReason（已由 `/api/video` 路由生成）："首帧图里含真人，被模型隐私审核拦截（Seedance 不接受真人首帧图）。已自动尝试改用「参考图模式」生成——若仍失败，点重试，或把这一镜做成不含正脸真人的画面" |
| 首帧与参考图混用冲突 | Seedance 系列模型同时传 `imageUrl` 与 `referenceImageUrls`，网关返回 `cannot be mixed` | failReason："首帧与参考图不能同时使用（Seedance 限制）。已自动改用其一重试，请点重试"；前端已在 `runShot` 中按模型能力自动避免混传，此为安全网 |
| 降级生成（参考图被拒） | 参考图被网关拒收（非审核），`degraded=true` | 静默降级：内部标记 `degraded`，控制台输出 warn；**不向用户弹提示**；分镜卡可展示小角标 tooltip 显示降级原因（可选） |
| 抽取上一镜尾帧失败 | 文本/智能多帧模式，`extractLastFrame(prev.videoUrl)` 返回空 | 该镜置为失败态，failReason 使用 `extractLastFrame` 返回的 `reason`（默认："未能读取上一镜尾帧，无法衔接，请重试"）；toast 同步提示；**不降级为纯文生**（降级会导致镜头首帧断裂） |
| 读取编辑视频首尾帧失败 | 「编辑视频」时抽当前视频首帧或尾帧失败 | 该镜复原 `status=done`，toast 提示："读取视频首尾帧失败，请重试" |
| 并发重复生成防护 | 某镜 `status=gen` 期间再次触发该镜生成 | `genInFlight.has(id)` 检测，直接返回，不重复启动；按钮此时已置灰 |
| 长时生成进度反馈 | 生成任务进行中 | 初始 5%，每 1600ms 累加 2%，封顶 90%；获得结果后立即跳至 100%；后段刻意放缓避免进度条"卡满" |
| AI 安全改写失败 | 点「AI 改写重试」，`/api/generate`（scene=`studio-safe-rewrite`）失败 | toast 提示："改写失败，请重试"；保留原画面描述不变，`改写重试`按钮恢复可点 |
| 额度耗尽 | 后端返回 HTTP 429 或 `error` 含 quota / rate | failReason："生成频率过高或额度不足，请稍后重试" |

**fail_reason 映射表**

| fail_reason（含） | 展示文案 |
|------------------|----------|
| timeout / HTTP 504 | 生成超时（视频耗时过长），请重试 |
| real person / privacy / 人像 | 首帧图里含真人，被模型隐私审核拦截（Seedance 不接受真人首帧图）。已自动尝试改用「参考图模式」…请点重试 |
| cannot be mixed / first/last frame | 首帧与参考图不能同时使用（Seedance 限制）。已自动改用其一重试，请点重试 |
| content / safety / policy / 审核 / sensitive + image / 图 | 输入图片未通过审核：某个元素参考图被判敏感…去③取消本镜绑定该元素后重试 |
| content / safety / policy / 审核 / sensitive + text / prompt / 文 | 画面描述文字未通过审核，请修改文字（点「去改写」） |
| content / safety / policy / 审核 / sensitive（类型不确定） | 内容未通过审核：可能是文字，也可能是输入图片（人物/元素参考图、上一镜尾帧） |
| channel / unavailable / no available | 模型暂时不可用，请稍后重试 |
| 429 / quota / rate | 生成频率过高或额度不足，请稍后重试 |
| 网络异常（fetch catch） | 网络异常，请重试 |
| 其他 / 兜底 | 生成失败，请重试（额度已退还） |

## 五、镜头图（关键帧）生成类（智能多帧模式）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 角色缺参考图就生成镜头图 | 有角色元素但 `refImg` 为空，点「生成全部镜头图」 | 确认弹窗提示："有 N 个角色还没有参考图，缺参考图的镜头人物无法锁定、可能不一致。建议先到②「一键生成全部图片」给角色出参考图。仍要现在生成镜头图吗？"；用户确认后继续 |
| 单镜镜头图生成失败 | `/api/image` 返回错误或无图片 | 静默跳过该镜（不中断整批）；全部完成后在 kfProg 中体现；**不自动降级**，该镜智能多帧模式将在③生成视频时报错"本镜还没有镜头图" |
| 用户停止镜头图生成 | 点「停止」按钮 | 中止所有在飞 kfAborts 请求；toast 提示："已停止生成镜头图"；已完成的镜头图保留 |
| 智能匹配风格推断失败 | `/api/generate`（scene=`studio-style-match`）失败或无匹配风格 | 静默降级：视频风格保持「智能匹配」（不锁定为具体风格）；生图/生视频仍可继续；不弹错误 |
| 重复点击「生成全部镜头图」 | `kfBusy=true` 时再次触发 | 函数顶部 `if (kfRunning.current || kfBusy) return`；按钮置灰，无响应 |

## 六、AI 辅助功能类（各步横切）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 逐镜 AI 扩写失败（`/api/video-prompt`） | 超时或返回空 | 本地 `localExpand` 降级兜底；若本地也失败则保留原描述不变；toast 提示："优化失败，请重试"；扩写按钮恢复可点 |
| 逐镜扩写时输入为空 | 该镜 `shotDesc` 为空就点「AI 扩写」 | toast 提示："请先填写画面内容，再点 AI 扩写" |
| 自动识别出镜元素失败（`studio-shot-elements-fill`） | LLM 返回空或解析失败 | 静默降级：该镜 `assetRefs` 不更新；整批完成后 toast 汇总；不报错 |
| 「自动识别出镜元素」前无元素 | 元素库为空就点「自动匹配出镜元素」 | toast 提示："请先在②添加场景/角色/道具" |
| 语音匹配失败（`studio-voice-match`） | 配音分配 LLM 返回空 | 静默降级：所有镜头使用默认音色（不分说话人）；不打断配音流程 |

## 七、导出合成类（Step ④）

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 浏览器不支持 MediaRecorder | `recordSupported()` 返回 false | toast 提示："当前浏览器不支持视频录制导出"；不启动录制；可提示用户换 Chrome |
| 并发导出拦截 | `exporting=true` 时再次点「导出长视频」 | 不启动第二次录制（函数顶部 `if (exporting) return`）；导出按钮已置为 loading 态 |
| 跨域视频代理下载失败 | `/api/media?url=...` 返回错误或 blob 为空 | 该镜静默回退：`blobUrl=null`，合成时用封面海报（Ken Burns 动画）填充，不中断整片合成；不向用户弹错 |
| 音频上下文不可用 | `typeof AudioContext === "undefined"` 或 `audioDest` 创建失败 | 静默降级：`audioCtx=null`，合成流中不包含音轨；视频仍正常导出（无声版） |
| 导出文件命名 | 录制完成 `rec.onstop` | 文件名格式：`制作大片_{N}镜.{ext}`，`ext` 由 `mimeExt(rec.mimeType)` 推断（webm / mp4）；toast 提示："已导出长视频到本地（.ext）" |
| 成片自动入库失败（配额超限） | `addWork(card)` 捕获 `QuotaExceededError` | toast 提示："本地存储空间不足，作品可能未保存"；导出文件已落盘，不受影响 |
| 单镜视频素材入库失败 | 每镜生成成功后 `addMaterial` 失败 | 静默忽略（console.warn）；不影响生成流程与整片导出 |

## 八、存储与配额类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 项目持久化失败 | `persistProject()` 写入 localStorage 失败 | 静默处理（不向用户报错）；下次打开项目列表不会出现该项目 |
| 本地存储空间不足 | `localStorage.setItem` 抛出 `QuotaExceededError` | toast 提示："本地存储空间不足，历史记录可能无法保存"；视频生成与导出正常继续，不因存储失败中断 |
| 生成失败退还额度 | 任一镜头最终失败 | failReason 兜底文案包含"额度已退还"（`生成失败，请重试（额度已退还）`）；避免用户误以为已扣费 |
| 高清额度提示 | 视频质量选择 1080P | 参数区展示提示："高清消耗 2 倍额度"，让用户在生成前知悉消耗 |
| 配额耗尽 | 后端返回 HTTP 429 / `quota_exceeded` | failReason："生成频率过高或额度不足，请稍后重试"；如有配额弹层逻辑，弹层提供「明日再来」与「联系客服解锁次数」 |

## 九、配音与音频类

| 场景 | 触发条件 | 预期 UI 表现 |
|------|----------|--------------|
| 不配音的分镜生成 | `settings.配音 === "不配音"` | `generateAudio=false` 写入 `/api/video` body，API 不生成音轨；视频生成流程不变 |
| 导出时无音频可合成 | 所有镜头 `generateAudio=false` 或 `AudioContext` 不可用 | 合成录制流中不加载音频节点；导出纯视频（无声），文件格式不变 |
| 声音克隆录制失败 | 浏览器不支持 `MediaRecorder` 或 `getUserMedia` 被拒绝 | toast 提示："录音失败，请检查麦克风权限"；录制 UI 复原；不影响其他配音功能 |
| 音色收藏写入失败 | `localStorage.setItem("mofun.studio.voiceFavs", …)` 在隐私模式下抛出异常 | 静默忽略（`try/catch`）；收藏状态仅本次会话有效，不报错 |

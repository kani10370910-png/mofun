# 魔方智绘 · 小墨 AI 回复逻辑方案

> 配套文档：[Agent框架-小墨.md](./Agent框架-小墨.md)  
> 参考：[Miora](https://miora.design/)「Brief → 澄清 → 交付」对话节奏  
> 目标：用户随口说需求时，小墨能**一轮一轮问清楚**，引导其走完创作，而不是只抛一句「已识别意图」。

---

## 0. 问题与目标

### 现状问题
用户说「做一个 IP」后，当前回复类似：
> 已理解需求，识别为「品牌设计 · IP设计」…

这只完成了**贴标签**，没有帮用户把「可生成的创意描述」凑齐，也无法自然接到提案 / 出图 / 进工作台。

### 目标（对齐 Miora）
1. **先确认方向**：你要做的是哪一类能力（IP / Logo / 海报…）。  
2. **再补关键信息**：一次只问 1～2 个最影响结果的问题，并给**可点选项**。  
3. **信息够了再动手**：提案 / 出图 / 给「进入创作」卡，用户始终可控。  
4. **记住已说过的**：同会话不再重复问；有品牌记忆则直接复用。

一句话：**小墨不是搜索框，是会带人做完活的创意搭档。**

## 1. 通用回复节奏（所有能力共用）

### 1.1 五拍结构

每一通有效对话，尽量落在下面五拍（可压缩，不可乱序）：

| 拍 | 名称 | 小墨做什么 | 用户感知 |
|----|------|------------|----------|
| ① | **接住** | 复述用户目标 + 人设语气 | 「听懂了」 |
| ② | **定位** | 点明 Specialist / 意图标签 | 「走的是 IP 这条线」 |
| ③ | **追问** | 按优先级问槽位，带选项卡 | 「我只要点几下」 |
| ④ | **收敛** | 汇总已确认信息，问「可以开始了吗」 | 「心里有数」 |
| ⑤ | **推进** | 提案 / 生成预览 / 「进入 xxx 工作台」 | 「能继续做下去」 |

### 1.2 追问铁律

1. **同组固定 2 问**（参考 Miora）：相关槽位同一张卡片一起问；答完一轮再 ack（如「A × B」）进入下一组。选项 ≤ 6 个。  
2. **先问「决定画面/文案成败」的槽**，装饰项（尺寸、数量）后置或给默认。  
3. 用户说「你定 / 随便 / 都可以」→ 填**智能默认**，口头说明默认值，进入下一拍。  
4. 用户一次说全 → **跳过已填槽**，直接收敛。  
5. 用户跑题 / 换需求 → 重新 ①②，旧槽可保留可清空（询问一句即可）。  
6. 连续 2 轮用户不答关键槽 → 给「用默认继续」+「进入工作台自己填」双出口，禁止死循环追问。  
7. **视觉类确认闸门**：槽齐后先出「方向策划」文本（色系/气质/Slogan），用户点「确认方案，开始生成」再出图。  
8. **出图后建议栈**：确认延展 VI / 换视觉方向 / 调整配色 / 再生成。  
9. **品牌记忆**：跨会话注入已确认品牌名/品类/风格；确认生成时写回。  
10. **双意图接近**时展示确认卡，不静默猜错专家。

### 1.3 单轮回复模板（开发拼装）

```
[接住 1 句]
[定位：意图标签]
[思考块可选]
[正文：追问或汇总]
[选项卡 / 行动卡]
```

示例骨架：

```text
好的，美妆护肤品牌！现在再确认几个方向，帮你把定位做准：

识别意图 → 品牌设计 · IP设计

你更想要哪种 IP 气质？
[ 可爱 Q 版 ] [ 国潮拟人 ] [ 写实吉祥物 ] [ 我来描述 ]
```

（语气参考 Miora：先肯定已知信息，再收窄方向。）

### 1.4 三种推进出口

槽位达到「可开工」后，小墨必须给出至少一种出口（可多选）：

| 出口 | 何时用 | 行动卡文案示例 |
|------|--------|----------------|
| A. 对话内提案 | 创意尚模糊（IP/文案/活动主题） | 「帮我出 3 个方案」 |
| B. 对话内生成 | 必填槽已齐且模块支持快生成 | 「直接出图 / 出文案」 |
| C. 进入工作台 | 需要精细表单、上传、多步（商拍图、大片、数字人） | 「进入 IP 设计」 |

**原则**：能对话内快速给「方向感」的用 A；能一键出结果的用 B；必须上传/多步骤的用 C，并预填已收集槽位。

## 2. 槽位模型（回复逻辑的数据基础）

每个 Specialist 定义：

```ts
type ReplySlot = {
  key: string;
  label: string;
  priority: 1 | 2 | 3;   // 1=必问且阻塞开工；2=强烈建议；3=可默认
  ask: string;             // 追问句
  options?: string[];      // 选项卡；无则自由输入
  extractHints: string[];  // 从用户原话里可匹配的信号
  defaultValue?: string;   // 「你定」时的默认
  mapsToForm: string;      // 对应模块表单字段名
};
```

**开工条件**：所有 `priority === 1` 的槽已填（或用户明确授权默认）。

## 3. 黄金路径详解：用户说「做一个 IP」

对齐模块 PRD：`IP创新设计` 核心必填是 **创意描述**；「帮我提案」可先出 3 套方案再填描述。

### 3.1 槽位表（IP · 创新，参考 Miora 同组双问）

默认 `mode=创新设计`（用户说「扩展/延展」才切扩展）。同 `group` 的两槽同一张卡片。

| group | key | 追问句 | 选项（示例） | 映射表单 |
|-------|-----|--------|--------------|----------|
| 1 | `brandName` | 品牌或特产叫什么？ | 自由输入 | 品牌 |
| 1 | `industry` | 属于哪个品类？ | 茶叶 / 美妆护肤 / 食品特产 / … | 品类 |
| 2 | `style` | 品牌气质更偏哪种？ | 自然草本 / 可爱 Q 版 / 国潮 / … | 创意描述·风格 |
| 2 | `audience` | 主要给谁看 / 谁用？ | 都市白领 25-35 / 亲子家庭 / … | 人群 |
| 3 | `subject` | IP 想做成什么形象？ | 茶拟人 / 竹拟人 / … | 创意描述·主体 |
| 3 | `usage` | 主要用在哪里？ | 吉祥物主视觉 / 表情包 / … | 用途 |

扩展设计额外（group 1）：

| key | 追问 | 选项 |
|-----|------|------|
| `extendType` | 这次想延展哪一类？ | 视角 / 场景 / 动作 / 表情 / 服装 |
| `ipImage` | 请上传已有 IP 图 | 我已上传 / 改成创新设计 |

### 3.2 对话剧本（创新设计 · Miora 双问）

**用户：** 做一个 IP  

**小墨：**
> 好呀！我来帮你做品牌 IP。先问你两个相关问题。  
> 识别意图 → **品牌设计 · IP设计**  
>  
> **卡片 Q1 · 品牌名** / **Q2 · 品类**（选项 chips）

**用户：** 苔间 → 美妆护肤  

**小墨：**
> 苔间 × 美妆护肤，这个组合很清晰。再确认两点：  
> **卡片 Q1 · 气质** / **Q2 · 人群**

**用户：** 自然草本 → 都市白领 25-35  

**小墨：**
> 自然草本 × 都市白领 25-35，这个组合很清晰。再确认两点：  
> **卡片 · 形象 + 用途**

答齐后：`[ 帮我出方案 ] [ 直接出图 ]`（对话内真实生成，不跳转）

### 3.3 信息充足后的出口

答齐三组后汇总槽位，**先出「品牌方向策划」确认卡**（含建议色系与 Slogan），再：
`[ 确认方案，开始生成 ] [ 先出 3 个备选方案 ] [ 调整方案方向 ]`

出图成功后建议栈：
`[ 确认主视觉，生成 VI 延展 ] [ 换一个视觉方向 ] [ 调整配色方案 ] [ 再生成一版 ]`

### 3.4 提案后的接法

用户点「帮我出 3 个方案」→ 调提案 API → 回复：

> 给你 3 个方向（点选用）：  
> **方案一**：……  
> **方案二**：……  
> **方案三**：……  
> `[ 用方案一 ] [ 用方案二 ] [ 用方案三 ] [ 都不满意，再说说 ]`

选用后 → 创意描述收敛 → 再给 `[ 直接出图 ]`。

### 3.5 信息充足时的压缩版

**用户：** 设计一个可爱的白茶姑娘 IP，国潮风，做表情包用  

**小墨：**（跳过已抽到的槽，只补缺组）
> 已记下：白茶姑娘 · 可爱国潮 · 表情包。  
> 识别意图 → 品牌设计 · IP设计  
>  
> `[ 帮我出 3 个方案 ] [ 直接出图 ]`  
> 也可以补充品牌名/品类，或者说「你定」。

## 5. 意图置信与「问错了」的回复

**铁律：用户每句自由文本都跑意图识别**（点选 chips /「你定」不重跑，以免打断填槽）。

| 识别结果 | 行为 |
|----------|------|
| 与当前专家一致 / 像在答槽（短答） | **keep**，继续追问或填槽 |
| 明确指向其他能力（如「生成艺术字」） | **switch**，清冲突槽，进新专家 |
| 尚无专家且高置信 | **set**，锁定专家 |
| 双候选接近 | **confirm**，出选择卡 |
| 低置信 | **category**，问文案/设计/视频/调研 |

### 5.1 高置信
直接进该能力的追问剧本。

### 5.2 中置信 / 双候选
> 你更可能是想做下面哪一件？  
> `[ IP 形象 ] [ 活动海报 ] [ 都不是，我再说说 ]`

### 5.3 低置信
> 我可以帮你做文案、品牌视觉、视频或调研。你更想先做哪一类？  
> `[ 文案 ] [ 品牌设计 ] [ 视频 ] [ 调研 ]`

### 5.4 用户纠正 / 换能力
> 好的，改做「AI 字体」。  
> （清空海报物料等冲突槽，保留仍通用的风格/品牌名等）

## 6. 从用户原话抽取（减少追问）

抽取规则优先于追问（`agent-slot` 或规则）：

| 用户说法含… | 预填 |
|-------------|------|
| 可爱 / Q 版 / 萌 | style=可爱Q版 |
| 国潮 / 新中式 | style=国潮 |
| 表情包 | usage=表情包 |
| 白茶 / 竹 / 笋 / 萝卜 | subject 对应拟人方向 |
| 朋友圈 / 小红书 | platform |
| 海报 / 易拉宝 | format |
| 口播 / 数字人 | video.avatar |
| 上传图 / 附件 | 标记 hasRefImage，商拍/扩展 IP 走上传槽 |

抽取结果要在回复里**用白话回读**，让用户可改：
> 我先按「可爱 + 表情包」理解，不对你再说一声就行。

## 7. 人设与文风（回复质量）

| 要 | 不要 |
|----|------|
| 短句、口语、像同事协作 | 长篇空洞「作为 AI…」 |
| 先确认已知，再问未知 | 重复用户刚说过的整段 |
| 给选项降低输入成本 | 连续三个开放填空 |
| 说清下一步会发生什么 | 未凑齐信息就假装已生成 |
| 农文旅语境自然（区县、特产、节庆） | 硬套互联网黑话 |

**固定自称：** 小墨。  
**思考开关：** 开 → 可输出「正在确认：主体 / 风格 / 用途」类 thinking；关 → 只出正文与卡片。

## 8. 与生成 / 工作台的衔接文案

### 8.1 对话内生成中
> 正在按你的设定出图，稍等几秒…  
（tool_start / tool_end）

> 精细调整（配色、延展、周边）在工作台更顺手。我已把刚才说的都带过去。

## 9. 异常与边界回复

| 情况 | 回复策略 |
|------|----------|
| 生成失败 | 致歉 + 原因摘要 + `[ 重试 ] [ 改描述 ] [ 进工作台 ]` |
| 用户只闲聊 | 轻回一句 + 拉回「今天想做文案、视觉还是视频？」 |
| 涉政敏感等 | 按安全策略拒答，给可做的替代方向 |
| 超出能力（如 3D 建模） | 说明边界，推荐最接近的模块（如 IP / 大片） |
| 会话过长 | 主动摘要 + 建议新建对话，旧会话进历史 |

## 11. 附录：IP 能力「信息充足」判定

满足任一即可进入出口 ⑤：

- **A.** `mode=创新` 且 `subject` + `style` 已填（可拼出 ≥ 20 字创意描述）  
- **B.** 用户粘贴了完整创意描述（≥ 30 字）并确认  
- **C.** 已选用「帮我提案」中的某一方案  
- **D.** `mode=扩展` 且已有 `ipImage` + `extendType`

未满足时，只允许追问或「用默认继续」，不允许空描述直接出图。

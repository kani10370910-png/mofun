# 算力换算说明

## 规则

**1 元人民币 = 100 算力**（向上取整）。

实现：`mofun/src/lib/pointCosts.ts`（`yuanToCompute` / `imageShotPoints` / `videoSecondsPoints` / `POINT_COST`）。

## 图片（按所选模型 · 元/张）

| 模型（UI） | 人民币 | 算力/张 |
|------------|--------|---------|
| Seedream 4.0 | 0.20 | **20** |
| Seedream 5.0 / MoFun区域文化大模型 / Z-Image | 0.22 | **22** |
| Seedream 4.5 | 0.25 | **25** |
| 高清重绘 / 局部重绘（Pro 档） | 0.32 | **32** |

动态：

- 活动文生图：`张数 × 当前模型单价`
- 活动图生图：`1 × 编辑模型单价`
- 商拍 / 店招：`张数 × 固定通道模型单价`（面板内 `state.model`）

## 视频（按模型 × 分辨率 × 有声 · 元/秒）

依据火山方舟刊例示例折算（5 秒样例 ÷ 5）。2K/4K UI 档实际按 **1080p** 计（与 `qualityToModelRes` 一致）。

### Seedance 1.5 Pro（有声约 2× 无声）

| 分辨率 | 无声 元/秒 | 有声 元/秒 | 有声 5s 算力 |
|--------|------------|------------|--------------|
| 480P | 0.080 | 0.160 | **80** |
| 720P | 0.172 | 0.346 | **173** |
| 1080P | 0.388 | 0.778 | **389** |

### Seedance 1.0 Pro（无原生有声）

| 分辨率 | 元/秒 |
|--------|-------|
| 480P | 0.150 |
| 720P | 0.322 |
| 1080P | 0.726 |

### Seedance 2.0 / Fast / Mini（按分辨率；原生有声不另乘）

| 模型 | 480P | 720P | 1080P* |
|------|------|------|--------|
| 2.0 | 0.462 | 0.994 | 2.478 |
| 2.0 Fast | 0.372 | 0.800 | 0.800（降级） |
| 2.0 Mini | 0.232 | 0.496 | 0.496（降级） |

\* Fast/Mini 官方不支持 1080 → 按 720 单价。

动态：`ceil(元/秒 × 秒数 × 条数 × 100)`。文生视频可选 1/2 条时乘条数。

数字人 OmniHuman：**1 元/秒 → 100 × 秒**。

## 文本生成（不计算力）

文案策划、市场调研、联想 / AI 扩写 / AI 优化、图转文、Studio 镜头脚本、IP 提案 / IP 故事等 **LLM 文本产出一律 0 算力**，按钮不展示算力角标。

| 能力 | 算力 |
|------|------|
| 社媒 / 公众号 / 品牌策划 | **0** |
| 市场调研 | **0** |
| 联想 / 扩写 / 脚本 / 提案 / 故事 / 图转文 | **0** |
| 本地抠图 / 演示消除·矢量 | **0** |

## 说明

- 本地 Qwen 通道按 Seedream Lite **同等商用成本**计费。
- Seedance 2.0 系列刊例含限时折扣时，产品侧仍用**刊例全价**，避免促销结束前后展示跳变；若要跟促销，改 `SEEDANCE_20*` 表即可。
- 文本类若日后要计费，改 `pointCosts.ts` 中 `RMB.llm*` / 对应 `POINT_COST` 即可。

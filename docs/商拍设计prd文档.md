# 商拍设计 PRD 文档

> 模块路径：品牌设计 → 商拍　|　页面 `/image?sub=product`  
> 文档版本：v3.0　｜　状态：已实现（商品出图台）  
> 适用产品：魔方智绘 · 农旅机构版  
> 关联文件：`src/components/image/ImageProductPanel.tsx`、`ImageEditor.tsx`、`ActiveGallery.tsx`、`src/data/productStudio.ts`、`src/data/productSeeds.ts`、`src/lib/productCutout.ts`、`src/lib/productDemo.ts`、`src/lib/productRunsStorage.ts`

---

## 功能概述

**商拍（商品出图台）**：面向县域农产品 / 文旅特产 / 伴手礼的电商与种草出图工作台。用户上传**商品实拍**，通过「商品换背景」能力，结合场景预设、自定义描述词库与平台尺寸，产出可上架的主图 / 产地场景图；右侧「生成历史 / 参考灵感」双 Tab，参考灵感为上图下文卡片，可一键套用。

**与「活动设计」的区别**

| 维度 | 商拍 | 活动设计 |
|---|---|---|
| 产物 | 商品主图 / 产地生活场景图 / 补充图溶图 | 海报 / 长图 / 菜单 / 易拉宝 / 宣传单 |
| 输入核心 | 商品实拍（必填）+ 可选场景 | 画面描述（文生图）或参考图（图生图） |
| 顶栏结构 | 无文生图/图生图 Tab | 文生图 / 图生图 Tab 切换 |
| 成图类型 | 无；由「场景预设」驱动（纯色 / 产地 / 补充图） | 自定义 / 海报 / 长图 / 菜单 / 易拉宝 / 宣传单 |
| 模型 | 固定 Seedream-5.0-lite，前端不可切换 | 可选 MoFun 区域文化大模型等 |
| 本地增强 | 仅**知识库**（无 Lora） | 知识库 + Lora（选区域文化大模型时） |
| 右侧编辑 | 无「编辑 / 深度编辑」入口 | 结果图支持编辑工作台与深度编辑 |

**模块说明**

- 左侧为独立「商品出图台」表单（不复用活动 Tab 骨架），默认走 **商品换背景**（`bgMode = aiscene`）。
- 上传商品实拍 → 可选场景预设 / 补充图 / 纯色背景 → 可选描述词库 → 选尺寸与数量 → 调图生图模型出图（有场景图时先合成参考图再送模型）。
- 右侧「生成历史」展示进度卡与结果图（支持只看收藏 / 复制 / 删除 / 下载 / 收藏 / 另存）；「参考灵感」展示 3 张样张，可套用模版或跳转场景。
- 出图后自动存入「仓库 · 我的作品」；生成历史持久化至 `localStorage`（`mofun.productRuns`）。

## 1. 商品换背景（主路径）

### 1.1 业务字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| 知识库 | 否 | 开关 | 默认开启；开启时服务端检索本地/远程知识库并注入 prompt；无 Lora 开关 |
| 商品实拍 | 是 | 上传 / 仓库 | 本地上传（jpg / jpeg / png / webp，≤ 10 MB）或点「仓库」选图；带预览与清除 |
| 场景预设 | 否 | 网格单选 | 首屏 6 格，可展开「更多预设选项」；再次点击已选项 → 取消选中（内部为「不使用预设」） |
| 自定义场景描述 | 否 | 多行 + 词库 | 选填；下方 Tab：**主体** / **装饰** / **光线**，点 tag 追加到描述 |
| 出图尺寸 | 是 | 下拉 | 自定义 / 电商主图 1:1 / 方版 1:1 / 竖版 3:4 / 竖版 9:16；「自定义」展开宽 × 高（px，最小 64） |
| 生成数量 | 是 | 分段 | 1 / 2 / 3 / 4，默认 1 |

**场景预设选项**

| 选项 | 说明 |
|---|---|
| 上传补充图 | 本地上传或仓库选 1 张场景图；出图时将商品图与补充图并排合成参考图再送模型 |
| 纯色场景 | 展开后可选 `#RRGGBB` 色板；走白底/纯色 prompt |
| 高山茶园 / 竹林青石 / 稻田秋收 / 果园枝头 / 山泉溪边 | 产地空景预设，静态底图在 `public/productcase/` |
| 农家餐桌 / 民宿窗台 / 厨房料理 / 原木静物 / 节日礼赠 | 生活氛围预设 |

> 场景缩略图优先读本地缓存；无 API 时仍可用静态 `productcase` 图展示与离线 DEMO 合成。

### 1.2 出图尺寸组

| 名称 | 像素 |
|---|---|
| 自定义 | 用户填写宽 × 高 |
| 电商主图 1:1 | 800 × 800 |
| 方版 1:1 | 1080 × 1080 |
| 竖版 3:4 | 1080 × 1440 |
| 竖版 9:16 | 1080 × 1920 |

### 1.3 描述词库（自定义场景描述）

| 分类 | 可选 tag（点击追加） |
|---|---|
| 主体 | 悬浮展示、平铺俯拍、模特佩戴、手持特写、3D 渲染、微距特写 |
| 装饰 | 热带植物、鲜花点缀、水珠、烟雾缭绕、丝绸飘带、几何石膏、光影斑驳、竹叶、麦穗、露珠 |
| 光线 | 自然光、柔光箱、硬光、侧逆光、轮廓光、霓虹光、晨光、夕阳 |

出图前 `expandProductDescLexicon` 将 tag 替换为对应完整 prompt 片段再拼接。

### 1.4 交互流程

1. （可选）开关**知识库**。
2. 上传 / 仓库选**商品实拍**（必填）。
3. （可选）选**场景预设**：无 / 纯色 / 产地生活 / 上传补充图。
4. （可选）在**自定义场景描述**中手输或点词库 tag。
5. 选**出图尺寸**、**生成数量**。
6. 点「**立即生成**」→ 切到「生成历史」→ 出进度卡 → 构建 prompt → 调 `/api/image` 图生图（带商品参考图；有场景时先 `composeFusionReference` 合成双图参考）→ 进度卡替换为结果图。
7. 出图后自动存入「仓库 · 我的作品」。

**底部 CTA 文案**

- 无场景：`商品换背景 · 生成 N 张`
- 有场景：`商品换背景·{场景名} · 生成 N 张`（纯色为「商品换背景·纯色」）

### 1.5 出图 prompt 策略

**固定约束（`productStudio.ts`）**

- `PRODUCT_REF_KEEP`：严格保留参考图商品主体、包装与标签。
- `PRODUCT_DEAI_SUFFIX`：写实商业摄影、去 CGI/塑料感、接触阴影自然等。

**按场景拼装（`buildAiScenePrompt` / 融合参考）**

| 场景 | prompt 要点 |
|---|---|
| 不使用预设 | 通用商品换背景 + 用户描述 |
| 纯色场景 | 白底/纯色棚拍，主体居中，电商过审感 |
| 产地/生活预设 | 商品为主体 + 预设场景 prompt（如「层叠茶垄与薄雾的高山茶园」） |
| 上传补充图（合成成功） | 保主体 + 放入补充场景环境 + 可选用户描述 + 去 AI 感 |
| 上传补充图（合成失败） | toast 降级为「商品图 + 文字场景」继续出图 |

**LLM 扩写（`/api/generate`，scene = `t2i-product`）**

- 按 `aiSceneExpandSub` 选模板：**产地场景**（非纯色预设）或 **白底主图**（纯色场景）。
- 系统模板含：白底主图、产地场景、生活场景、细节特写、礼盒套图、详情长图（见 `llm.ts` · `T2I_PRODUCT_PROMPTS`）。
- **实际上线路径几乎跳过扩写**：有商品实拍 / 套用灵感（`fromCase`）/ DEMO 模式时 `skipExpand = true`，直接送图生图 prompt。

**跳过扩写的场景（fromCase）**

- 参考灵感点「套用模版」：回填描述 + 场景 + 尺寸，标记 `fromCase`，不再二次扩写。

### 1.6 LLM 扩写模板示例（白底主图）

```
【输入参数】
用户描述：{{ user_input }}
区县/地区：{{ county_name }}（若为空则不强制融入地域元素）
图片比例：{{ image_ratio }}

【通用红线】
1. 输出为纯中文一段画面描述，不含英文、不加解释。
2. 商品主体外观必须真实可信，不虚构产地认证标识。
3. 按图片比例匹配构图；保持写实商拍质感。
4. 区县非空时自然融入地域景观或农特产气质。
5. 禁止水印、乱码文字；白底类禁止花哨道具抢主体。
6. 长度 150~250 字。

【白底主图专项】
- 背景纯白或极浅灰，主体居中，四边留白均匀。
- 柔和棚拍光，标签清晰可读。
```

> 产地场景 / 生活场景 / 细节特写 / 礼盒套图 / 详情长图各有同结构专项段落。

## 2. 右侧画廊：生成历史 / 参考灵感

### 2.1 生成历史

| 元素 | 说明 |
|---|---|
| 只看收藏 | 开关，仅显示已收藏的结果图 |
| 分组 | 按生成时间分「今天 / 昨天 / 更早」 |
| 行头 | 任务标签（如「商品换背景·高山茶园」）+ 尺寸 + 知识库 badge（若开启）+ 复制 / 删除 + 时间 |
| 进度卡 | 出图中显示「X% 完成」 |
| 结果图 | 按宽铺满；hover 出下载 / 收藏 / 另存 |
| 编辑 | **无**活动式「编辑 / 深度编辑」入口（`resultEdit={false}`） |

- 结果图点击放大预览。
- 预置假数据 1 条：`商品换背景·补充图`，图 `/productcase/product-mix-seed.png`（`productSeeds.ts`）。
- 历史持久化：`loadProductRuns` / `saveProductRuns`（`mofun.productRuns`）。

### 2.2 参考灵感

| 元素 | 说明 |
|---|---|
| 样张卡片 | 3 张真实案例（`productGalleryItems`），上图下文 |
| 点击卡片 | 左侧回填场景预设 + 出图尺寸（不动描述） |
| 套用模版 | 回填描述 + 场景 + 尺寸，标记 `fromCase` |

**样张清单**

| sub | name | 套用后场景 |
|---|---|---|
| 白底主图 | 茶罐白底主图 | 纯色场景 |
| 产地场景 | 高山茶园场景图 | 高山茶园 |
| 生活场景 | 民宿窗台氛围图 | 民宿窗台 |

## 3. 错误与校验

| 场景 | 用户提示 |
|---|---|
| 未上传商品实拍 | 请先上传商品图！ |
| 补充图模式未上传 | 请先上传场景补充图 |
| 自定义宽高无效 | 请填写有效的自定义宽高（最小 64px）！ |
| 上传格式不符 | 仅支持 JPG、PNG、WEBP |
| 上传超限 | 图片不能超过 10 MB |
| 场景拼图失败 | 场景拼图未成功，已改用商品图 + 文字场景继续出图 |
| 无待出图任务 | 没有待出图的任务，请检查配置 |
| 安全审核 | 描述内容未通过安全审核，请调整后重试 |
| 配额 | 今日生成次数已达上限 |
| 超时 | 商拍图生成超时，请稍后重试 |
| 全失败 | 未能生成合适的结果，请尝试修改描述或商品图 |
| 部分失败 | 已生成 x/n 张（部分超时），已存入「我的作品」 |
| 网络 | 网络错误，商拍图生成失败。 |
| 实拍读取失败 | 实拍图读取失败，请重新上传后重试 |
| 本地抠图失败 | 抠图失败，请检查图片后重试 |
| 本地存储满 | 本地存储空间不足，历史记录可能无法保存 |

> 说明：**自定义场景描述为选填**，不因描述为空拦截生成。

## 4. 已下线 / 未露出能力

以下能力在数据层或生成逻辑中仍保留，**当前左栏无入口**，默认用户不可达：

| 能力 | 内部 key | 说明 |
|---|---|---|
| 多角度批量 | `aimulti` | 正面/侧面/背面等角度批量出图 |
| 本地抠图白底 | `cutwhite` | WASM 抠图铺白底，不调 API |
| 透明底 | `transparent` | PNG 抠图 |
| 抠图色底 | `color` | 本地抠图 + 纯色 |
| 场景底（本地溶图） | `scene` | 预设场景本地合成 |
| 多任务卡 | white / scene / detail / multi / refine / handheld / gift | 已收拢为单一「换底抠图」 |
| 实拍精修预设 | 变清晰 / 去文字 / 去水印等 | `productRefinePresets`，无 UI |
| 画面风格 / 图生图预设 | `productStyles` / `productEditPresets` | 活动式字段，商拍未用 |
| 商品名称输入 | `productName` | 仅回填/入库用，无输入框 |

## 附：依赖接口

| 接口 | 用途 | 说明 |
|---|---|---|
| `/api/image` | 商品换背景出图 | `Seedream-5.0-lite`；带 `image`（商品图或合成参考图）；`useLora: false`；`useKB` 随开关 |
| `/api/generate` | 文生图扩写（极少触发） | SSE；scene = `t2i-product`；有实拍时通常跳过 |
| 知识库检索 | prompt 注入 | `kbServer` / WeKnora；`useKB=true` 时服务端注入 |
| `/api/proxy-image` `/api/download` | 结果图下载 | 跨域代理拉取 |

**关键约束速查**

| 项 | 值 |
|---|---|
| 固定模型 | Seedream-5.0-lite |
| 知识库 | 默认开；无 Lora |
| 商品图 | 必填；jpg/png/webp；≤ 10 MB |
| 生成数量 | 1~4 |
| 单 job 超时 | 90s；总预算 ≈ jobs × 90s + 20s |
| 重试 | 最多 3 次 |
| 作品 sub | 品牌设计 · 商拍 |

> 部署注意：静态导出（nginx 静态站）不含 `/api`，真实出图不可用，走 DEMO 离线合成；需出图的环境须用 Node 全栈部署或 Cloudflare Workers。

## 功能概述

「制作大片」是面向区县农业宣传、文化旅游、农旅融合等场景的**多分镜长视频生成编辑器**。用户从一句话需求出发，经「脚本编辑 → 角色场景道具 → 分镜制作 → 视频预览」**四步**，产出一条由多个分镜片段无缝拼接、可配字幕、可导出成片或剪映素材包的完整短片。

与「一句话生成视频」的区别：

| 维度 | 一句话生成视频 | 制作大片 |
|---|---|---|
| 产物 | 单段 5–15s 视频 | 多镜头长视频（最多 150 镜 / 约 10 分钟）|
| 流程 | 一步出片 | 四步全流程编辑器 |
| 一致性 | 单段内一致 | 跨镜锁角色/场景/道具（参考图注入 + 锁脸约束）|
| 衔接 | 无 | 文本/首尾帧模式：上一镜真实尾帧 → 下一镜首帧，强制无缝 |
| 管理 | 生成历史 | 项目文件（localStorage），首页展示，可重开续编 |

核心能力：
- **AI 剧本生成**：一句话直出结构化分镜级脚本（`studio-script-pro`），实时回填可编辑，支持上传脚本导入（txt/docx）；无多步向导。
- **角色场景道具一致性锚点**：为出镜元素建参考图，逐镜注入锁定跨镜外观一致；自动补主角并「锁脸」。
- **三栏分镜制作**：底部分镜条 + 中间大预览 + 右侧结构化脚本，脚本编辑与视频生成同屏完成。
- **逐镜/批量真实视频生成**：三种生成模式（文本生成 / 智能多帧 / 首尾帧），文本模式第 2 镜起强制以上一镜真实尾帧衔接。
- **内容安全兜底**：审核失败自动降级（逐步去参考图 → 纯文生）+ 一键 AI 改写重试，对用户无感。
- **合成预览与导出**：时间轴预览（镜头轨 + 字幕轨），导出成片 / 剪映素材包 / SRT 字幕。
- **项目化持久化**：生成即存项目文件，跨会话重开续编；参考灵感案例一键克隆套用。

## 全局视频设定（四步共享）

「新建大片」对话框与编辑器内「编辑项目」共享同一套视频设定，决定全片逐镜真实生成的参数。字段定义见 `src/data/video.ts › SETTING_FIELDS`。

| 字段 | 必填 | 类型 | 可选值 | 说明 |
|---|---|---|---|---|
| 模型 | 是 | 网格单选 | 见下表 | 逐镜真实视频生成使用的模型；**默认 Seedance 2.0 Mini** |
| 视频比例 | 是 | 图标按钮组 | 智能 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9（共 7 种）| 「智能」由模型自动判断最优比例 |
| 视频风格 | 是 | 风格卡片 | 智能匹配 / 写实 / 纪录片 / 航拍大片 / 温暖治愈 / 电影感 / 国风水墨 | 注入文本扩写与画面生成，锁全片基调 |
| 视频质量 | 是 | 滑块 | 480P（默认）/ 720P / 1080P / 2K / 4K | 1080P 及以上 ×2 额度；2K/4K 受模型限制实际以 1080P 生成 |
| 字幕 | 是 | 开关 | 显示（默认）/ 隐藏 | 预览与导出是否叠加字幕 |
| 知识库 | 是 | 开关 | 使用（默认）/ 不使用 | 剧本/扩写时是否引入区县知识库设定（`kbRule`）辅助行文 |

### 视频模型库

| 显示名 | modelId | 能力标签 | 说明 |
|---|---|---|---|
| Seedance 2.0 Mini | `seedance-2.0-mini` | 15s · 推荐 | 轻量版，出图稳定，**默认选中** |
| Seedance | `seedance` | 音画同步 · 15s | 标准版，支持环境音与音效同步 |

## 1. ① 脚本编辑

从一句话到完整镜头脚本：填写一句话需求点「立即生成」，一步产出结构化分镜级镜头脚本；右侧脚本区可编辑、可上传脚本、可复制/清空。当前界面**只有「立即生成」这一条主路径**（无多步向导）。

### 1.1 业务字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| 需求输入（input）| 是 | 多行文本 | 用户一句话需求（类型 + 故事），持久化保存；最多 500 字 |
| 片子类型（vType）| 否 | 下拉 | 文旅宣传 / 短剧 / 品牌广告 / 个人 IP 等，随「立即生成」带入 |
| 完整镜头脚本（script）| 是 | 多行文本 | 结构化镜头脚本，以「镜头N：」开头，下含 `【时长】/【画面】/【旁白】/【对白】`；「立即生成」产出，右侧可编辑 |
| idea / summary | — | 隐藏 | 会话状态保留字段，无 UI 入口；仅 `idea` 非空时触发后台兜底链路（见 1.2.3）|

### 1.2 功能描述

#### 1.2.1 场景模板库

左侧内置 4 种快捷起稿场景卡，点击自动回填需求输入框并切换片子类型，再点「立即生成」即可直接生成对应分镜脚本。

| # | 场景卡 | 示例填充内容 |
|---|---|---|
| 1 | 🌄 做文旅宣传 | 做一条2-3分钟的安吉文旅宣传片，展现高山云雾茶园与乡村美景，面向暑期学生群体 |
| 2 | 🏡 做民宿农家乐 | 为莫干山一家精品民宿拍一条温馨短片，突出田园慢生活、农家美食与亲子体验 |
| 3 | 🍊 农产品推广 | 写一条安吉白茶产地直采推广片，主打高山云雾、氨基酸高、限量预订、产地直发 |
| 4 | 🧧 非遗展示 | 做一条竹编非遗技艺展示片，展现匠人手艺细节与代代传承的故事 |

> 默认状态提示语：「一句话描述要生成的视频，或上方选个场景自动填充（最多 500 字）」

#### 1.2.2 立即生成（主路径）

填一句话（类型 + 故事）→「立即生成」→ 调 `studio-script-pro` 一步产出结构化镜头脚本，SSE 流式回填右侧「镜头脚本」框。

输入可含目标时长（如"2-3分钟"），解析为 `【目标总时长】` 约束注入提示词。

#### 1.2.3 后台兜底（无独立 UI）

离开①时触发：
- `script` 为空 + `idea` 非空 → 后台走 `studio-summary` → `studio-shots` 生成（兜底链路）
- `script` 为空 + `idea` 也为空 + `input` 非空 → 走 `studio-script-pro` 兜底
- `script` 已有内容 → 不重新生成

当前界面没有「生成原始创意/多步向导」按钮，`studio-idea / summary / shots` 属遗留/兜底 scene，非用户可见步骤。

#### 1.2.4 自动拆分镜

①已有脚本 + ③分镜全为空白 → 离开①（含直接点顶部步骤 tab 跳至②/③）时自动据脚本拆分镜到③。仅在「分镜全为空白未动过」时触发，不覆盖已编辑/已生成的分镜。

#### 1.2.5 上传脚本

按钮文案「上传脚本」，支持 `.txt / .md / .csv`（可靠）和 `.docx`（前端原生解压 xml 取文本）；`.pdf / .doc` 给转换提示；限 10MB；有内容时二次确认覆盖。

#### 1.2.6 复制 / 清空

一键复制当前脚本 / 清空（有内容时二次确认）。

### 1.3 系统提示词

每条 system 追加 `STUDIO_SAFE_RULE`（内容安全）+ `styleRule(styleHint)`（全片风格统一）+ `kbRule(useKB)`（知识库）。

**主路径·立即生成（scene: `studio-script-pro`）**

```
你是一位拥有15年从业经验的顶级短视频 / 漫剧编剧，曾为抖音、快手头部账号操刀过数百条破千万播放的脚本。你深度掌握情绪节奏、镜头语言、爆款钩子与观众心理。

【创作哲学】
1. 前3秒定生死：开场必须用画面或台词制造悬念、反差、强烈情绪冲击，让观众停住。
2. 每镜有目的、无废镜：每个镜头要么推进剧情、要么强化情绪、要么塑造人物；高密度推进，禁止空镜。
3. 用画面说话：能用画面表达的绝不依赖旁白；台词克制、精准、口语化、接地气。
4. 情绪弧线是命脉：平静→扰动→冲突→爆发→余韵；全片至少一个「反转/意外」、至少一个「情绪特写」。
5. 结尾必有钩子：留白/提问/悬念，让人想评论、想转发、想等续集。

【输出格式】（严格遵守，便于系统自动拆分镜；不要任何标题、装饰线、emoji 或 markdown 标记）
每个镜头严格以「镜头N：」单独一行开头（N 从 1 依次递增），其下依次分四个中文方括号标签、各自单独成行：
【时长】整数秒（每镜不得低于 4 秒，一般 4-8 秒，叙事镜可到 10 秒；逐镜必给，不要省略）
【画面】必写，硬性下限不少于 80 字，要素依次写足：
  · 景别（远/全/中/近/特写）+ 拍摄角度 + 运镜方式；
  · 人物站位 + 核心动作 + 面部神态 + 关键道具及状态；
  · 分层恒定光效（光源方向、色调、明暗层次）+ 场景环境细节；
  · 出场角色外貌与服饰（核心视觉锚点，各镜必须完全一致）；
  · 真实尺寸比例基准，避免比例失调；
  · 「衔接前置」：本镜结尾姿态/光效/道具位置，供下一镜承接。
  · 只写看得见的画面，绝不把旁白/台词文字混进来。
【旁白】仅确有画外解说时写；没有就整行省略，不写「无」，不凭空编造。
【对白】仅确有人物说话时写，「角色名：（情绪语气）台词」每句一行；没有就整行省略。

【硬性约束】
- 镜头数量：约每 10 秒 2-3 个镜头，节奏紧凑。
- 台词密度：60 秒视频台词总量不超过 180 字。
- 一致性：同一角色外貌/服饰/光效在各镜保持一致。
- 负面规避：无画面扭曲、无人物变形、无五官崩坏、无帧间闪烁、无透视错乱、无主体漂移、无穿模、无比例失调、
  无角色全程静止、无纯环境空镜、无缓慢渐变光影、无舒缓慢拉运镜、无动作停顿留白、无无意义情绪水帧；全程无字幕水印。
+ STUDIO_SAFE_RULE + styleRule + kbRule
```

**智能匹配风格（scene: `studio-style-match`）** — 进③生成时若风格为「智能匹配」自动触发

```

写实、纪录片、航拍大片、温暖治愈、电影感、国风水墨。
只输出风格名本身（四个字以内，必须是上面 6 个之一），不要任何解释、标点或多余文字。
```

## 2. ② 角色场景道具

手动添加或自动读剧本生成角色/场景/道具，给参考图（本地上传 · 仓库选图 · AI 生成）。在分镜制作为每镜勾选出镜元素，生成时注入参考图保持跨镜一致。

### 2.1 元素字段（Asset）

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| id | — | string | 唯一标识（手动 `a-*` / 自动 `auto-*`）|
| kind | 是 | 枚举 | 角色 🧑 / 场景 🏞️ / 道具 🎁 |
| name | 是 | string | 元素名（2–10 字，可编辑）|
| desc | 否 | string | 结合剧本写好的结构化画面描述（自动添加/扩写产生，生图优先用）|
| refImg | 否 | string | 参考图 URL / base64（一致性锚点核心）|
| voice | 否 | string | 角色音色（供④配音按说话人分配）|

### 2.2 功能描述

#### 2.2.1 手动添加

分「新增角色 / 场景 / 道具」，新卡片插入列表最前便于立即编辑。

#### 2.2.2 自动提取

读①脚本，调 `studio-assets` 提取清单（只加元素，不生图）。仅替换上次自动添加（`auto-` 前缀）的元素，保留手动项。

- **道具尽量齐全**：提示词要求把人物手持/使用/佩戴/操作的所有关键物件都列出（手机、相机、工具、器皿、篮子、帽子、招牌等，最多 12 个）。
- **按画面过滤**：只保留名字真出现在某镜「画面」里的元素；仅在旁白/对白/背景叙述提到、任何画面都不出现的不建卡片（省额度、避免③「未使用元素」）。

#### 2.2.3 一键生成全部图片

对分镜里用到、还没参考图的元素，依次「优化描述（`studio-asset-desc`）→ 生图（`/api/image`）」回填。首次点击先弹「生成设置」（localStorage 标记只拦一次）。

#### 2.2.4 AI 生成参考图（右侧常驻面板）

选中元素后右侧「生图 / 改图」面板：画面描述（可 AI 扩写·结合剧本）+ 选模型 + 立即生成；结果可一键回填为参考图。面板高度填满右列。

#### 2.2.5 本地上传 / 仓库选图

上传 ≤10MB 的 jpg/png/webp，或从统一仓库选择器（`LibraryPicker`，`filter="image"`）选图。

#### 2.2.6 其他操作

- 点击参考图放大查看（`ImageLightbox`）
- 顶部类型筛选：全部 / 角色 / 场景 / 道具

## 3. ③ 分镜制作（脚本 + 视频 · 三栏合一）

原「分镜脚本 + 分镜视频」合并为一个三栏编辑器：**底部选镜 · 中间预览 · 右侧编脚本**，脚本编辑与逐镜视频生成同屏完成。

### 3.1 界面布局（三栏）

**顶部工具条**
- 生成模式切换（文本生成 / 智能多帧 / 首尾帧）
- 智能多帧时：「生成全部镜头图」/「镜头图全部重做」二合一（全部已有镜头图 → 自动切为「镜头图全部重做」）
- 最右：「批量生成全部视频」/ 生成中变「暂停生成」

**中间大预览**（选中镜头）
- 已生成：视频播放（右上角 `当前/总数`，如 `2/10`；左上角已生成角标）
- 未生成：「待生成」居中占位 / 生成进度% / 失败态
- 下方操作行：编辑（视频生视频）· 仓库 · 下载 · 生成本镜 / 重新生成 · 删除

**右侧脚本面板**（选中镜头，高度填满内容区）
- 锁人物镜头图（智能多帧/首尾帧时展示，即 `firstFrame`，可上传/仓库/AI 生成）
- 画面描述（`AutoGrowTextarea`，自适应高度，默认展示全文）
- 字幕
- 运镜 / 景别 / 时长步进器（2–15s，步长 1s）
- 出镜元素（勾选②里的元素，同时在画面描述中以 `@元素名` 标记）

**底部分镜条**（所有镜头横排，宽度 = 中间预览列宽，超出横向滚动）
- 每格：左上角序号、右下角时长、状态角标（生成中%橙 / 失败红 / 待生成居中占位 / 已生成无角标）
- 点选切换选中镜头；**拖拽排序**（`moveShotTo`）；**镜头间「＋」插入**空白镜头（`insertShotAt`）；末尾「创建空白分镜 / 本地 / 仓库」新增

### 3.2 镜头字段（Shot）

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| id | — | string | 唯一标识 |
| shotDesc | 是 | string | 画面描述（`@元素名` 为 UI 标记，生成前去除）|
| caption | 否 | string | 字幕（默认继承旁白/对白，可独立编辑）|
| voiceScript | 否 | string | 带说话人前缀的口播脚本（供配音按说话人分配音色）|
| camera | 否 | 枚举 | 运镜：航拍俯瞰 / 缓缓推近 / 特写镜头 / 环绕拍摄 / 上移俯拍 / 横移跟拍 |
| shotSize | 否 | 枚举 | 景别：远景 / 全景 / 中景 / 近景 / 特写 |
| assetRefs | 否 | string[] | 出镜元素引用（跨镜一致性）|
| dur | 否 | number | 时长（秒）；默认由脚本标注或均分得出 |
| locked | 否 | boolean | 锁定：脚本重拆时保留该镜内容 |
| status | — | 枚举 | idle / gen / done / failed |
| videoUrl | — | string | 已生成视频片段 URL（外部 CDN）|
| firstFrame / lastFrame | — | string | 智能多帧的「锁人物镜头图」/ 首尾帧模式的首尾帧 |

### 3.3 镜头数 / 时长约束

- **镜头数**：1–150（150 × 4s ≈ 10 分钟上限）；由①脚本拆分决定，之后用底部「＋」插入 / 删除 / 末尾新增增减。
- **单镜时长**：
  - 脚本生成 / 均分：**4–15s**（剧本标注则沿用，否则兜底均分）
  - 右侧步进器手动调整：**2–15s**（下限 2s）
  - `/api/video` 内部钳制：**5–10s**（模型限制，对用户不可见）
- **总时长** = 各镜时长之和

### 3.4 生成模式（genMode）

**进③智能默认**（`genModeTouched=false` 时）：②有元素参考图 → 智能多帧；无图 → 文本生成。手动切过后 `genModeTouched=true`，之后不再自动改。

| 模式 | key | 帧策略 | 说明 |
|---|---|---|---|
| 文本生成 | `text` | 纯文生（首镜）/ 上一镜真实尾帧为首帧（后续镜）| 强制无缝衔接 |
| 智能多帧 | `smart` | 每镜先生成「锁人物镜头图」（注入角色参考图），再以该图做 i2v | 每镜独立，不跨镜承接 |
| 首尾帧 | `keyframe` | 首帧（第 2 镜起继承上一镜尾帧）+ 尾帧（可上传/仓库/AI 生成）| flf2v 模式 |

#### 生成模式与模型功能对照

| 生成模式 | 文本生成 | 智能多帧 | 首尾帧 |
|---|---|---|---|
| Seedance 2.0 Mini | ✅ | ✅（t2v 生镜头图 + i2v）| ✅ |
| Seedance | ✅ | ✅ | ✅ |
| Seedance Fast | ✅ | ✅ | ✅ |

> 三种模式在三个模型上均可使用；音画同步差异见上方「多模型功能支持对照表」。

### 3.5 镜头图按钮（智能多帧）

「生成全部镜头图」与「镜头图全部重做」**二合一**：
- 全部镜头都已有镜头图 → 按钮切为「镜头图全部重做」（覆盖重生成，不影响已生成视频）
- 否则 → 「生成全部镜头图」（补齐还没镜头图的镜头）
- 位置：批量生成全部视频按钮左侧

「锁人物镜头图」= 该镜 `firstFrame`，可上传 / 仓库 / AI 生成（`genAllKeyframes` 注入出场角色参考图 + 当前风格出图）。

### 3.6 功能描述

- **画面描述框自适应高度**（`AutoGrowTextarea`）：按内容自动撑高，默认展示全部文本。
- **AI 扩写（逐镜）**：把该镜画面描述调 `/api/video-prompt` 优化，带前面所有镜头做叙事衔接上下文；失败本地兜底。扩写在原文基础上进行，保留引号台词不改。
- **自动绑定出镜元素**：画面描述中出现的元素名自动勾选进 `assetRefs`（同时加 `@` 标记）；含人物关键词但没匹配到角色名时自动补主角色；精确匹配不到时走 AI 语义识别（`studio-shot-elements-fill`）。
- **改内容不作废视频**：改画面描述 / 元素 / 字幕 / 运镜 / 景别 / 时长都不清掉已生成视频；只有点「重新生成」才覆盖。
- **批量生成全部视频**：按顺序依次生成，每镜完成后 `ensureVideoCached` 缓存到本地再抽尾帧生成下一镜；任一镜失败即停止；生成中按钮变「暂停生成」。

### 3.7 跨镜一致性（角色/场景/道具）

- **参考图注入（reference_image）**：只注入本镜勾选元素的参考图（不全局注入所有角色），按「角色 > 场景 > 道具」排序，不截断；参考图不占首帧位置。
- **安全网**：本镜画面有人物但没绑到带参考图的角色 → 自动补入主角色参考图。
- **锁脸约束（faceLock）**：有带参考图的角色时，强约束「必须与参考图为同一人，五官/发型/发色/服饰一致，绝不换脸」。
- **一致性文字约束（consistencyNote）**：逐一点名出镜元素外观在所有镜头中与参考图一致；整片画面风格严格统一。

### 3.8 逐镜视频生成与无缝衔接

- **强制无缝（文本/首尾帧）**：镜头 N（N≥2）首帧 = 镜头 N-1 真实视频尾帧（`extractLastFrame` 抽帧，优先本地 IndexedDB 缓存）；抽帧失败标记失败让用户重试，不静默降级。
- **重生成中间镜「两头无缝」**：被重生成的镜头前后都已有视频时，首帧接前一镜尾帧、尾帧接后一镜首帧（flf2v）。
- **智能多帧**：每镜以自己的「锁人物镜头图」做 i2v，不跨镜承接。

### 3.9 编辑视频（视频生视频）

对已生成的某一镜做**局部修改**——保持首尾帧不变，仅按文字要求重画中间画面（如改衣服颜色、加雾气）。

- **入口**：中间预览「编辑」按钮（该镜 `status=done` 且有 videoUrl）→「编辑视频」弹窗（原视频预览 + 修改要求必填 + 生成）
- **流程**：从原视频抽首帧+尾帧 → `runShot` flf2v 重画中间 → 新 videoUrl 替换该镜并重新入库
- **提示词注入**：`这是对已有视频的局部修改：在保持人物外观、场景环境、整体画面风格与原视频完全一致的前提下，仅按要求改动对应局部，其余不动：{修改要求}`

### 3.10 内容安全降级

| 降级步骤 | 操作 | 对用户 |
|---|---|---|
| 第 1 次拦截 | 去除参考图，保留首帧衔接 | 无感（静默重试）|
| 第 2 次拦截 | 去全部输入图，纯文生 | 无感（静默重试）|
| 最终失败 | 标记 `failed`，返回 `degradeReason` 内部留痕 | 失败态 + 「AI 改写」按钮 |
| 用户手动 | 点「AI 改写」→ `studio-safe-rewrite` → 自动重生成 | 可见 |

### 3.11 使用模型 / 提示词

- **拆分镜**：本地 `makeShots`（按「镜头N：」段落 + `parseShotParts` 拆 `【画面】/【旁白】/【对白】/【时长】`）
- **逐镜 AI 扩写**：`/api/video-prompt` → `qwen3-max`，`SYSTEM_VIDEO_PROMPT_OPTIMIZE`
- **视频生成**：`/api/video` → Seedance 系列；content = `text` + `first_frame` + 可选 `last_frame`（flf2v）+ `reference_image[]`（锁一致）
- **逐镜 prompt 组装**（`runShot` 本地拼装）：`[视频风格前缀] + [承接说明] + 画面描述 + 出镜元素文字 + [编辑要求] + 景别/运镜 + consistencyNote + [尾帧要求]`
- **出镜元素 AI 识别**：`/api/generate`（scene: `studio-shot-elements-fill`）→ `qwen3-max`

## 6. 数据结构与持久化

### 6.1 会话单例（`studioSession`）

模块级单例，`useSessionField<T>(key)` 读写，`getStudioSnapshot()` 取快照；组件卸载后生成在后台继续。

### 6.2 项目文件（localStorage `mofun.studio.projects`）

- `StudioProjectMeta`：id / name / updated / ts / count（分镜数）/ cover（首个已生成视频 URL）/ fav（收藏）
- `StudioProject.state`：完整会话状态，用于重开
- 存储时剔除首尾帧/大参考图 base64（保留外链 videoUrl），避免配额溢出；溢出派发 `mofun:storage-quota` 事件

### 6.3 视频缓存（IndexedDB）

生成成功的分镜视频存 IndexedDB，首访下载入库，之后秒开；抽尾帧优先读本地完整 blob。

## 7. API 路由总览

| 路由 | 方法 | 用途 | 模型/依赖 |
|---|---|---|---|
| `/api/generate` | POST(SSE) | 剧本生成（`studio-script-pro`）/ 元素提取（`studio-assets`）/ 描述优化（`studio-asset-desc`）/ 风格匹配（`studio-style-match`）/ 审核改写（`studio-safe-rewrite`）/ 出镜元素识别（`studio-shot-elements-fill`）等 | `qwen3-max` |
| `/api/video-prompt` | POST | 逐镜画面描述 AI 扩写 | `qwen3-max` |
| `/api/video` | POST | 逐镜真实视频生成 | Seedance 系列（2.0 Mini / Seedance / Seedance Fast）|
| `/api/image` | POST | 元素参考图 / 镜头图生图（文生图/图生图）| Z-Image / Qwen-Image / Seedream 4.0 · 4.5 · 5.0-lite |
| `/api/media` | GET | 外部视频同源代理（Range 转发，抽尾帧/播放）| — |
| `/api/proxy-video` · `/api/proxy-image` | GET | 下载/Canvas 防跨域代理 | — |

> 线上静态导出版（内网 Nginx）不含 `/api`，故线上无实时 AI 生成，仅作演示浏览。

## 8. 与「一句话生成视频」的联动

一句话生成视频「生成历史」卡片的**去制作大片**按钮：自动在制作大片中创建新项目，填入提示词（→ 脚本）与该视频（→ 镜头 1，status=done），跳转到③分镜制作。同一条视频再次点击不覆盖已建项目。

## 9. 关键约束速查

| 项 | 值 |
|---|---|
| 流程 | 四步：① 脚本编辑 · ② 角色场景道具 · ③ 分镜制作（脚本+视频三栏合一）· ④ 视频预览 |
| 镜头数 | 1–150（150×4s≈10min）；由脚本拆分 + 底部插入/删除决定 |
| 单镜时长 | 手动步进 2–15s；脚本生成/均分 4–15s；`/api/video` 内部钳 5–10s |
| 默认视频设定 | 模型：**Seedance 2.0 Mini** · 比例：16:9 · 风格：智能匹配 · 质量：480P · 字幕：显示 · 知识库：使用 |
| 生成模式默认 | 进③按②是否有元素图智能选：无图→文本生成 / 有图→智能多帧（手动选过则不覆盖）|
| 视频模型 | Seedance 2.0 Mini（默认）/ Seedance / Seedance Fast |
| 图片模型 | Z-Image（默认）/ Qwen-Image / Seedream 4.0 / 4.5 / 5.0-lite |
| 参考图注入 | 只注入本镜勾选元素（角色优先）；缺角色参考图时自动补主角色 |
| 生图清晰度 | 1K/2K/4K → 1920²/2048²/4096² |
| 上传脚本 | ≤10MB，txt/md/csv/docx 可靠，pdf/doc 提示转换 |
| 存储 | localStorage `mofun.studio.projects`；视频缓存 IndexedDB |
| 部署 | 静态导出 `out/` → 内网 Nginx `.../html/out`（`deploy_code_tar.py`，详见 `scripts/DEPLOY.md`）|

② 用户操作 · 生成流程图（全路径闭环）

← ① Agent 框架流程图

从用户视角描述：进对话 → 说明需求 → 答双问 → 确认方案 → 出图/出文 → 迭代 → 退出/再开。 每种可点操作都标出，且最终都能回到「可继续对话」或「回首页再进」形成闭环。 不强制跳转功能页 点图=预览灯箱

1. 用户总览闭环

外环：首页 ⇄ 对话。内环：提问 → 回答 → 确认 → 生成 → 建议 → 再提问。

flowchart TB
  Hero([首页 Hero]) --> Enter{用户如何进入对话?}
  Enter -->|输入框回车/发送| Chat[进入对话态]
  Enter -->|点意图芯片| Chat
  Enter -->|点案例| Chat
  Enter -->|恢复历史会话| Chat

  Chat --> Hub(["对话中可随时：打字 / 点选 / 上传 / 顶栏退出"])

  Hub --> AskNeed[说明想做什么]
  AskNeed --> Clarify[回答双问卡片
或点选项 / 「你定」]
  Clarify --> More{还要再问?}
  More -->|是| Clarify
  More -->|否·视觉类| Plan[阅读方向策划]
  More -->|否·文案/视频/调研| Ready[看到「提案/生成」按钮]

  Plan --> PlanAct{用户选择}
  PlanAct -->|确认方案开始生成| Gen
  PlanAct -->|先出3个备选| Propose
  PlanAct -->|调整方案方向| Clarify
  Ready --> ReadyAct{用户选择}
  ReadyAct -->|直接生成| Gen
  ReadyAct -->|先出方案| Propose

  Propose --> Pick{选用方案?}
  Pick -->|用方案N| PlanOrReady[回到策划确认或生成出口]
  Pick -->|都不满意再说说| Clarify
  PlanOrReady --> PlanAct
  PlanOrReady --> ReadyAct

  Gen --> Result{结果}
  Result -->|成功出图/出文| Deliver[交付气泡 + 建议栈]
  Result -->|失败| Retry[重试卡]
  Result -->|缺参考图| UploadHint[提示上传后重试]

  Deliver --> After{用户接下来}
  After -->|点图片| Lightbox[灯箱预览 · Esc关闭] --> Deliver
  After -->|再生成一版| Gen
  After -->|换视觉方向| Clarify
  After -->|调整配色| ColorPick[选配色] --> Gen
  After -->|VI延展| Gen
  After -->|重新出方案| Propose
  After -->|继续打字新需求| AskNeed
  After -->|顶栏首页/新建| Hero

  Retry -->|重试| Gen
  Retry -->|改先出方案| Propose
  Retry -->|改口说明| AskNeed
  UploadHint -->|上传附件| Hub
  UploadHint -->|再点生成| Gen

  Hub --> Exit{顶栏首页或新建对话?}
  Exit -->|是| Hero
  Exit -->|否| Hub

2. 进入 / 退出 / 历史（会话级闭环）

flowchart TB
  H[首页 Hero] --> I1[在输入框输入 Brief]
  H --> I2[点展示区意图/案例]
  H --> I3[打开历史 · 点某会话]
  I1 --> C[对话态：顶栏首页不选中]
  I2 --> C
  I3 --> C2[恢复 messages + agentState]
  C2 --> C

  C --> U1[继续对话操作]
  U1 --> C

  C --> X1[点顶栏「首页」]
  C --> X2[新建对话]
  X1 --> Save[持久化当前会话到历史]
  X2 --> Save2[持久化 / 清空为空状态]
  Save --> H
  Save2 --> H
  H --> I1

flowchart TB

5. 方向策划确认（视觉类必经）

适用：IP / Logo / 活动海报 / 店招 / AI 字体。未点确认则不会出图。

flowchart TB
  Plan[展示品牌/视觉方向策划
色系 · Slogan · 主体…] --> Act{用户点击}

  Act -->|确认方案，开始生成| Gen[进入生成]
  Act -->|先出 3 个备选方案| Prop[进入提案]
  Act -->|调整方案方向| Rev[改气质/人群/主体/品牌/补充]
  Rev --> ReAsk[重新双问或补充]
  ReAsk --> Plan

  Prop --> Props[3 个方案气泡]
  Props --> PAct{用户点击}
  PAct -->|用方案一/二/三| Plan2[回到策划确认带选用内容]
  PAct -->|都不满意，再说说| Free[自由补充]
  Free --> Plan
  Plan2 --> Act

  Gen --> After(["第6节结果闭环"])
  After -->|换方向回来| Plan

6. 生成 / 提案结果 —— 成功·失败·缺图全路径

flowchart TB
  Start([用户点了生成或提案]) --> Busy[出现「正在调用…」感]

  Busy --> Ok{结果}
  Ok -->|提案成功| Three[3 方案 +「用方案N」]
  Ok -->|生成成功·图| Imgs[图片气泡]
  Ok -->|生成成功·文| TextOut[长文/口播/调研文本]
  Ok -->|失败| Fail[错误说明 + 重试卡]
  Ok -->|缺商品图/IP扩展图| NeedUp[明确提示先上传]

  Three --> Pick[选用或重说] --> Loop(["回策划/生成"])
  Imgs --> ClickImg[点击图片 → 灯箱预览]
  ClickImg -->|Esc / 关闭| Imgs
  Imgs --> Stack[建议栈按钮]
  TextOut --> Stack

  Stack --> S1[再生成一版] --> Start
  Stack --> S2[换一个视觉方向] --> Ask(["回双问"])
  Stack --> S3[调整配色方案] --> Colors
  Colors --> PickColor[点色板] --> PlanLike[更新策划或直接出图] --> Start
  Stack --> S4[确认主视觉/Logo，生成VI延展] --> Start
  Stack --> S5[重新出方案] --> Start
  Stack --> S6[继续打字微调] --> Chat(["回对话输入"])

  Fail --> F1[重试生成/提案] --> Start
  Fail --> F2[改走另一出口] --> Start
  Fail --> F3[改需求重说] --> Chat

  NeedUp --> Up[点附件上传 1～4 张图]
  Up --> Start

  Ask --> Loop
  Chat --> Loop
  Loop --> Start

7. 按能力的用户路径差异（均闭环回建议栈或双问）

用户想做典型双问是否策划确认生成前额外操作交付后建议
IP 形象品牌+行业 → 风格+人群 → 主体+用途要扩展模式须上传 IP 图VI / 换方向 / 配色 / 再生成
Logo品牌名+风格等要—VI / 换方向 / 配色 / 再生成
活动海报物料+主题+风格要可先 3 方案再确认换方向 / 配色 / 再生成 / 再提案
店招 / 字体店名或文字+气质要—换方向 / 配色 / 再生成
商拍场景等否（ready）必须上传商品图再生成 / 再提案
社媒文案平台+主题+语气否可先提案再生成完整版再生成 / 再提案
公众号/品牌文案主题/卖点否直接生成再生成
数字人口播角色+脚本否可「帮我写一版」提案再生成 / 再提案
一句话成片 / 大片一句话/Brief+氛围否直接生成文案向结果再生成
调研三类品牌/行业/品类否直接生成报告再生成

表中每一行的终点都可以：继续点建议、继续打字、或顶栏回首页 —— 闭环成立。

8. 异常与边界操作（仍闭环）

flowchart TB
  U[用户操作] --> E{边界情况}

  E -->|点「进入工作台」类 handoff| T1[Toast：请在对话中完成] --> Cont[继续对话]
  E -->|生成中重复猛点| T2[replying 锁 · 忽略重复] --> Cont
  E -->|点助手气泡复制/赞/踩/更多| T3[本地反馈 · 可重新生成该轮] --> Cont
  E -->|灯箱打开时按 Esc| T4[关闭预览] --> Cont
  E -->|上传非图片| T5[Toast 请上传图片] --> Cont
  E -->|网络/密钥失败| T6[失败重试卡] --> Cont
  E -->|未确认就想出图| T7[被闸门拦截提示] --> Plan[去点确认方案] --> Cont
  E -->|会话半路刷新| T8[可从历史恢复] --> Cont

  Cont --> U
